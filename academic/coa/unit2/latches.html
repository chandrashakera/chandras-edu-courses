Latches

⏱ 16 min read 📝 Quiz inside

The previous topic described the general shape of a sequential circuit: combinational logic plus a feedback loop that remembers state. A latch is the simplest possible version of that idea — a single stored bit, built from nothing more than ordinary gates cross-wired so each gate's output feeds back as another gate's input.

In simple terms: a latch is two gates feeding each other, so it holds a 1 or a 0 by itself; Set and Reset change what it holds.

The SR Latch

Cross-coupling two NOR gates — each gate's output feeding back as one of the other gate's inputs — produces a circuit with two stable states, which is exactly what's needed to remember one bit:

SR latch with two cross-coupled NOR gates.

Top gate: Q = NOR(R, Q′). Bottom gate: Q′ = NOR(S, Q).

S=R=1 forces both Q and Q′ to 0, breaking the Q=Q̄′ relationship the latch depends on — this combination must always be avoided.

Worked Example — Tracing a Sequence

Starting from Q=0 (reset), apply S=1,R=0 (Set): Q becomes 1. Next apply S=0,R=0 (Hold): Q stays at 1 — the latch remembers the 1 even though neither input is currently asserting it. Next apply S=0,R=1 (Reset): Q returns to 0. This hold-in-between behavior — the output staying at its last value while both inputs are 0 — is the entire point of the circuit: it's memory.

The Gated D Latch

The SR latch's forbidden state is an inconvenient thing to avoid by hand every time. Driving S=D and R=D′ (D inverted) makes S and R always complements of each other, eliminating the forbidden state by construction — S=R=1 simply can't happen if R is wired to always be the opposite of S. Adding an Enable (EN) input — via two AND gates gating D and D′ before they reach the SR core — adds control over exactly when the latch updates:

While EN=1, Q follows D continuously ("transparent"); when EN drops to 0, Q freezes at whatever D was last. This level-sensitive behavior — transparent for as long as the enable is high, not just at one instant — is the key thing an edge-triggered flip-flop (next topic) adds on top of.

🚀 Beyond the textbook: a gated D latch is exactly what's inside many microprocessor bus-multiplexed address latches (e.g., the 74LS373 octal latch) — the enable line holds the address stable on the data bus while the CPU switches over to sending actual data on the same physical pins.

Common Pitfalls

  • Driving a plain SR latch with S=R=1. This actively breaks the Q=Q̄′ relationship, not just "an invalid input" — the resulting state when both return to 0 is a race, not a defined value.
  • Assuming a latch only changes output when it's told to. A gated D latch is transparent — Q tracks D continuously the entire time EN=1, not just at a single moment. Any glitch on D while EN is high passes straight through to Q.
  • Confusing "gated" with "clocked." EN is a level (high/low), not a clock edge — the latch is still level-sensitive even though it has an enable pin, which is exactly what separates it from a flip-flop.

Applications

  • Address latches in bus-multiplexed systems (classic microprocessors that share address and data on the same pins) use exactly the transparent/latched behavior of a gated D latch to hold the address stable.
  • Debounce circuits for mechanical switches sometimes use an SR latch directly — a single-pole double-throw switch naturally drives S and R from its two contacts, and the latch's Hold state rejects the switch's mechanical bounce.
  • The next topic, Flip-Flops, builds directly on the latch — a flip-flop is fundamentally two latches (master and slave) combined to fix the level-sensitivity problem.
