Counter Design — Solved Problems

⏱ 30 min read 📌 Supplementary — beyond the syllabus
In simple terms: to design a synchronous counter, list each state and the next state, ask "what must each flip-flop input be to make that change?" using the excitation table, then simplify each input with a K-map.

These problems use the Ripple Counters and Synchronous Counters topics. Synchronous design follows six steps: (1) state sequence, (2) number of flip-flops, (3) state table with next states, (4) flip-flop inputs from the excitation table, (5) K-map per input, using unused states as don’t-cares, (6) check what the unused states do.

Excitation Tables

Q → Q(next)J KTD
0 → 00 X00
0 → 11 X11
1 → 0X 110
1 → 1X 001

1. Synchronous Counter Design

Problem 1 — mod-6 Synchronous Up Counter with JK Flip-Flops (000 → 101 → 000)

Present ABCNext ABCJA KAJB KBJC KC
0000010 X0 X1 X
0010100 X1 XX 1
0100110 XX 01 X
0111001 XX 1X 1
100101X 00 X1 X
101000X 10 XX 1

Unused states 110 and 111 are don’t-cares.

JA = BC      KA = C
JB = A′C     KB = C
JC = 1       KC = 1        (C toggles every clock)
Unused states: 110 → 111 → 000   — the counter returns to the main sequence by itself (self-correcting).

Problem 2 — Counter for the Sequence 0, 1, 2, 4, 5, 6 (Repeat) with JK Flip-Flops

Present ABCNext ABCJA KAJB KBJC KC
0000010 X0 X1 X
0010100 X1 XX 1
0101001 XX 10 X
100101X 00 X1 X
101110X 01 XX 1
110000X 1X 10 X
 
JA = B    KA = B
JB = C    KB = 1
JC = B′   KC = 1
Unused states: 011 → 100,  111 → 000   — self-correcting.

Notice how many inputs become 1 or a single variable — unused states as don’t-cares make arbitrary-sequence counters cheap.

Problem 3 — 3-Bit Gray-Code Counter with T Flip-Flops (000, 001, 011, 010, 110, 111, 101, 100)

Present ABCNext ABCTATBTC
000001001
001011010
011010001
010110100
110111001
111101010
101100001
100000100
 
TA = A′BC′ + AB′C′ = C′(A ⊕ B)
TB = A′B′C + ABC   = C(A ⊕ B)′
TC = (A ⊕ B ⊕ C)′          (TC = 1 when the state has an even number of 1s)
All 8 states are used — no don’t-cares and no lock-out check needed.

For a T flip-flop, T = 1 exactly where that bit changes — just compare each present and next bit.

2. Ripple (Asynchronous) Counters

Problem 4 — mod-6 Ripple Counter

Use a 3-bit ripple counter (negative-edge JK flip-flops with J = K = 1; each Q drives the next clock).
It must count 000 … 101 and reset at 6 = 110.
Reset logic: CLR′ = (Q₂ · Q₁)′ — a 2-input NAND to the active-low clear of all three flip-flops.
(Q₀ is not needed: 110 is the first state in which Q₂ = Q₁ = 1.)
The counter enters 110 for a few nanoseconds, then clears to 000 — a short glitch state.

Mod-10 (decade) ripple counter: same idea with four flip-flops — NAND of Q₃ and Q₁ (1010) clears the counter.

Problem 5 — Maximum Clock Frequency: Ripple vs Synchronous (4-bit)

Each flip-flop has tpd = 10 ns; each AND gate 5 ns (ignore setup time).

Ripple:       the last flip-flop settles after 4 × 10 = 40 ns
              f(max) = 1 / 40 ns = 25 MHz
Synchronous:  all flip-flops clock together; the longest path is one flip-flop + one AND gate
              (with parallel carry gates) = 10 + 5 = 15 ns
              f(max) = 1 / 15 ns ≈ 66.7 MHz

Ripple vs Synchronous — Summary

FeatureRipple (asynchronous)Synchronous
ClockOnly the first flip-flop; each output clocks the nextCommon clock to all flip-flops
DelayAdds up: n × tpdOne tpd + gate delay, any n
SpeedSlowerFaster
GlitchesBrief false states while bits rippleNone in normal counting
Extra logicNone (just reset gating for mod-N)AND gates or K-map logic per input
Typical useLow-speed, low-power dividersCounters inside CPUs and fast systems

Practice Problems

  1. Design a mod-5 synchronous counter (000 → 100) with JK flip-flops; check the unused states.
    Show answer

    JA = BC, KA = 1; JB = C, KB = C; JC = A′, KC = 1. Unused: 101 → 010, 110 → 010, 111 → 000 — self-correcting.

  2. Design the sequence 0, 1, 3, 7, 6, 4 (repeat) with D flip-flops.
    Show answer

    DA = B, DB = C, DC = A′ — it is a 3-bit Johnson counter. Unused 010 and 101 form their own loop (010 → 101 → 010), so it is not self-correcting.

  3. Which NAND inputs reset a ripple counter to make it mod-12?
    Show answer

    Q₃ and Q₂ (1100).

  4. A 5-bit ripple counter uses flip-flops with tpd = 12 ns. Find fmax.
    Show answer

    1 / (5 × 12 ns) ≈ 16.7 MHz.

Common Pitfalls

  • Skipping the unused-state check — a counter can lock into an unused loop (practice problem 2); always trace every unused state.
  • Using the characteristic table instead of the excitation table — design needs "which input causes Q → Q(next)".
  • Resetting at the last valid state — a mod-6 ripple counter resets at 6 (110), not at 5 (101).
  • Adding all delays in a synchronous counter — only the longest single path between clock edges counts.
