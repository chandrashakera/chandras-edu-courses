Other Counters

⏱ 18 min read 📝 Quiz inside

The last two topics covered the two main counter families in depth: ripple (asynchronous) and synchronous counters. This closing topic rounds out the picture with two counters built directly from a shift register — the ring and Johnson counters — plus a brief look at the decade counter as a general building block.

In simple terms: a ring counter passes a single 1 around a loop of flip-flops; a Johnson counter feeds back the inverted bit, so it gets twice as many states from the same flip-flops.

Ring Counter

Feed the last stage's output straight back into the first stage's input of a shift register, with no external serial data at all, and the register becomes a self-contained counter — a ring counter:

Four-bit ring counter: Q₃ feeds back to D₀.

  • Number of states: N states for N flip-flops — the single 1 (or single 0) just circulates.
  • 4-bit sequence, pre-loaded to 1000: 1000 → 0100 → 0010 → 0001 → 1000 …
  • Must be pre-loaded (e.g., to 1000) — reset alone gives 0000, which is a valid-looking but stuck state: Q₃=0 feeds D₀=0 forever, so it never starts circulating on its own.

Johnson Counter (Twisted-Ring Counter)

Feed back the inverted last output instead of the plain one, and the single circulating bit becomes a spreading/retreating band of 1s and 0s:

Four-bit Johnson counter: Q₃′ feeds back to D₀.

  • Number of states: 2N states for N flip-flops — twice the ring counter, since the inverted feedback takes twice as long to return to the starting pattern.
  • 4-bit sequence, starting from reset (0000): 0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000 …
  • Self-starting from the all-0 reset state — unlike the ring counter, 0000 isn't a stuck state here, because Q₃′=1 feeds D₀=1 on the very next clock, immediately kicking off the sequence.

BCD / Decade Counter

A decade counter is simply any counter that cycles through 10 states before wrapping back to 0 — the general name for what both dedicated counter topics in this unit built a version of. The ripple counter topic built one by adding a NAND reset gate to a plain 4-bit ripple counter; the synchronous counter topic's 4-step design procedure can equally be run against a 10-state sequence to derive a version that wraps 1001→0000 with no reset gate at all, purely from its next-state logic. From the outside, both look identical:

Decade counter: counts 0000 to 1001, with a carry output at 9 for the next decade.

Common decade-counter ICs reflect this same ripple-vs-synchronous split: the 7490 is a classic ripple decade counter, while the 74160/74162 family is synchronous and additionally supports the parallel-load pattern from the Registers topic — letting the count be forced to an arbitrary starting digit instead of always beginning at 0.

Common Pitfalls

  • Powering up a ring counter and expecting it to count. Without pre-loading exactly one stage to 1, a ring counter can power up in the all-0 state and simply sit there forever — it needs an explicit preset pulse before the first clock.
  • Forgetting Johnson counters need external decoding to identify each state. Unlike a ring counter, where the single active bit directly tells you the state, a Johnson counter's states aren't one-hot — identifying "which of the 2N states is this" needs a small 2-input gate per state (comparing adjacent bits).
  • Assuming "decade counter" implies one specific internal design. It only describes the external behavior (10 states, wraps at 9→0) — the ripple and synchronous topics show two completely different internal circuits that both qualify.

Applications

  • Johnson counters are used to build glitch-free ring oscillators and simple state sequencers (e.g., traffic-light controllers) since each state differs from its neighbor in only one bit, avoiding decoding glitches from multiple bits changing at once.
  • LED chaser / marquee displays are a direct, visible application of a ring counter — the single circulating 1 lights exactly one LED at a time, moving down the strip each clock pulse.
  • Decade counters are the core of any digital circuit that displays or counts in decimal — digital clocks, frequency counters, and event counters all chain decade counters, one per displayed digit.
