Combinational Circuits

⏱ 7 min read 📝 Quiz inside

Unit 1 covered bits, gates, and Boolean algebra. In this unit, we use that to build real circuits — adders, comparators, decoders, encoders, multiplexers. All of these share one property: they are combinational. This page explains what that means.

Definition

A combinational circuit is a group of logic gates connected together, where the output depends only on the current inputs — never on past inputs, and never on a clock. The same set of inputs always produces the same output, no matter when you apply them.

This is what separates a combinational circuit from a sequential circuit, covered later in this unit:

⚠️ If a circuit's output depends on more than just its current inputs — for example, if flip-flops store the circuit's own past output and feed it back in as an input — it is a sequential circuit, not a combinational one. Sequential circuits start with the Latches & Flip-Flops topic later in this unit.

The n-Input, m-Output Block Model

Every combinational circuit fits the same basic shape: n inputs go in, m outputs come out. Each output is a Boolean function of the inputs. There is no feedback — no gate's output ever loops back to an earlier gate.

Fig 1: The general shape every combinational circuit takes — n inputs in, m outputs out, decided purely by the present input combination

In real systems, a combinational circuit's inputs often come from a storage register, and its outputs are often stored back into a register. If those registers are counted as part of the circuit, the whole thing becomes a sequential circuit — because now it has memory.

Because there's no feedback, the output always settles to a stable value shortly after the inputs change. This short delay is called propagation delay. A circuit with feedback can instead get "stuck," or keep changing on its own — that's memory, and a combinational circuit must never have it.

Truth-Table Specification

For n input variables, there are 2ⁿ possible input combinations. Each combination gives exactly one output value. This is why a truth table can fully describe any combinational circuit — and why the same circuit can also be described with Boolean equations instead. Both mean the same thing.

Worked Example — Counting Rows

A circuit with 3 inputs has 2³ = 8 possible input combinations. So its truth table needs exactly 8 rows — one for every combination, each with a defined output.

Common Pitfalls

  • More gates doesn't mean "not combinational." What matters is whether there's feedback — not how many gates the circuit has.
  • A truth table isn't complete until every row has an output. Even inputs that seem unlikely still need a defined output value.

Applications

  • Every circuit in the rest of this unit — adders, comparators, decoders, encoders, multiplexers — is a combinational circuit.
  • A CPU's ALU (arithmetic logic unit) is a large combinational circuit — it computes a result from its inputs with no memory of earlier instructions.
