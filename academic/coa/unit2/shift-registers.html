Shift Registers

⏱ 22 min read 📝 Quiz inside

What a Shift Register Is

A shift register is a cascade of flip-flops sharing one common clock, where each stage's D input is simply the previous stage's Q — so on every clock pulse, every stored bit moves one position down the chain:

In simple terms: a shift register passes its bits along one place per clock — a bucket brigade for bits — so data can enter or leave one bit at a time.

Four-bit shift register: each Q feeds the next D on every clock edge. Adapted from M. Morris Mano and Michael D. Ciletti, Digital Design, Fig. 6.3.

Whether a register counts as "serial" or "parallel" on each side is purely about how data gets in and out — the internal shifting structure above never changes. The four combinations of serial/parallel in and out give the four standard shift register configurations.

SISO — Serial-In, Serial-Out

Data enters one bit at a time at Din and exits one bit at a time from the last stage, Q₃ — exactly the plain chain above, used purely for its shifting action:

Typical use: time delay lines and signal buffering, since the output is simply the input delayed by N clock cycles.

SIPO — Serial-In, Parallel-Out

Same chain, same serial input — but now every stage's Q is also tapped out as its own separate pin, so all 4 bits become available together once the last one has shifted in:

Typical use: serial-to-parallel conversion — a UART receiver shifts incoming bits in one at a time, then reads Q₀–Q₃ together as one completed byte.

PISO — Parallel-In, Serial-Out

Each stage gets a 2-to-1 MUX in front of its D input — the same load-control idea as a parallel-load register — choosing between the previous stage's Q (shift) and an external parallel bit In (load). One cell of the chain looks like this (every stage repeats this exact cell, sharing one SHIFT/LOAD′ control line):

One PISO cell. SHIFT/LOAD′=1 selects Qn-1 (shift in from the previous stage); =0 selects In (load this stage's parallel bit directly). The final stage's Q is the serial output.

Chaining four such cells together, each stage's MUX output feeding its own flip-flop and each flip-flop's Q feeding the next stage's shift input, gives the complete 4-bit PISO register:

SI (serial-in) ties the very first stage's shift input low when there's no earlier stage to shift from. I₀–I₃ are the four parallel-load pins, and every MUX shares the same SHIFT/LOAD′ control line and CLK.

Typical use: parallel-to-serial conversion — a UART transmitter loads a whole byte in parallel in one clock, then shifts it out one bit per clock afterward.

PIPO — Parallel-In, Parallel-Out

All 4 bits load independently and all 4 are read independently — no bit ever has to pass through another stage. Structurally this is just 4 D flip-flops sharing one clock, with no chaining between them at all:

Parallel-in, parallel-out: no connections between stages — all four bits load together on the clock edge.

Typical use: fast temporary register storage — this is functionally identical to the plain register from the previous topic, just framed here as the "no shifting at all" endpoint of the shift-register family.

Shift vs. Parallel-Load Operation

PISO and PIPO both need a control line telling every stage, on each clock, whether to shift or to load — exactly the SHIFT/LOAD′ line from the PISO cell above:

SHIFT/LOAD′Each Stage's D Input BecomesResult
1 (Shift)Previous stage's Q (serial-in for the first stage)Data moves one position per clock
0 (Load)External parallel bit InAll stages capture parallel data simultaneously

SISO and SIPO don't need this line at all — with no parallel-load path built in, they only ever shift, so the MUX (and its control line) simply isn't there.

Common Pitfalls

  • Confusing SIPO/PISO direction. The first letter always describes how data enters (Serial or Parallel), the second how it exits. SIPO goes in one bit at a time and comes out all at once; PISO is the reverse.
  • Forgetting that SHIFT/LOAD′ is sampled on every clock edge, not just once. Leaving it at 0 (load) after the intended load clock means the register keeps re-loading the same external data instead of shifting, silently overwriting any shifted-in bits.
  • Assuming PIPO needs a shift path at all. A pure PIPO register (like the diagram above) has no inter-stage wiring whatsoever — confusing it with PISO/SIPO's chained structure is a common source of wiring mistakes.

Applications

  • UART serial communication is the textbook SIPO/PISO pairing — a transmitter's parallel byte is shifted out one bit at a time (PISO), and the receiver reassembles incoming bits back into a parallel byte (SIPO).
  • SISO chains are used as simple digital delay lines, deliberately holding a signal for a fixed number of clock cycles.
  • PIPO registers are the standard choice for CPU pipeline stage buffers, where an entire word must be captured and released together every cycle.
