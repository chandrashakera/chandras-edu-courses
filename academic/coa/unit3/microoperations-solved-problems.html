Register Transfer and Microoperations — Solved Problems

⏱ 30 min read 📌 Supplementary — beyond the syllabus

Register transfer questions in exams ask one thing in many forms: what is in each register after this clock pulse? This page works through the common types — transfers over a common bus, the arithmetic circuit's eight functions, logic microoperations used as masks and inserts, the shift microoperations with overflow, and a multi-step trace through the arithmetic logic shift unit. Every answer is shown in binary and checked step by step, followed by practice problems with answers.

In simple terms

A microoperation is one small action done in one clock pulse: copy, add, AND, shift. To solve a trace, take the registers as they are before the clock edge, apply every transfer enabled in that pulse at the same time, and write the new values. Then move to the next pulse.

Quick Reference

MicrooperationRTLEffect (n-bit register R)
Logical shift left / rightR ← shl R, R ← shr RBits move one place; a 0 enters the vacated end
Circular shift left / rightR ← cil R, R ← cir RThe bit leaving one end enters the other end
Arithmetic shift leftR ← ashl RMultiply by 2; 0 enters R0; overflow Vs = Rn−1 ⊕ Rn−2 (before the shift)
Arithmetic shift rightR ← ashr RDivide by 2; sign bit Rn−1 is kept
Selective set / complement / clearA ← A ∨ B, A ← A ⊕ B, A ← A ∧ B′Bits of A where B = 1 are set / flipped / cleared
MaskA ← A ∧ BBits of A where B = 0 are cleared
InsertA ← A ∧ mask, then A ← A ∨ BClear a field, then OR in the new value

Notation: registers are 8 bits unless stated (bit 7 on the left). Hexadecimal values are written without a prefix, as in the textbook; question papers often add a suffix H (96H) or prefix 0x (0x96) for the same number.

Solved Problems — Register Transfer

Problem 1: Transfers over a common bus

Four 8-bit registers A, B, C and D share a common bus built from multiplexers. The select lines choose the source: S1S0 = 00 → A, 01 → B, 10 → C, 11 → D. A register loads the bus value on the clock edge when its load input is 1. Initially A = 3C, B = A5, C = 0F, D = 71.

(a) Find all four registers after each pulse of this sequence. (b) Swap A and B using C as a temporary register.

PulseS1S0Loads enabled
110D
201A, C
311B
 
(a)        RTL              A    B    C    D
    Initial                     3C   A5   0F   71
    Pulse 1    D ← C            3C   A5   0F   0F
    Pulse 2    A ← B, C ← B     A5   A5   A5   0F
    Pulse 3    B ← D            A5   0F   A5   0F

    (b) Initially A = 3C, B = A5
    Pulse   S₁S₀   Load   RTL      A    B    C
    1       00     C      C ← A    3C   A5   3C
    2       01     A      A ← B    A5   A5   3C
    3       10     B      B ← C    A5   3C   3C

Answer: (a) A = A5, B = 0F, C = A5, D = 0F; the original D = 71 is lost at pulse 1. (b) Three pulses: C ← A, A ← B, B ← C. One bus carries only one source per pulse, so the swap cannot be done in fewer. With separate direct paths between A and B, the statement A ← B, B ← A works in one pulse, because both registers load the values present before the clock edge.

Problem 2: All eight functions of the arithmetic circuit

The 4-bit arithmetic circuit adds A, an input Y chosen by S1S0 (00 → all 0s, 01 → B, 10 → B′, 11 → all 1s) and the input carry Cin: D = A + Y + Cin. For A = 1011 and B = 0110, find D and the output carry Cout for every combination.

S1S0CinYMicrooperationDCout
0000000Transfer A10110
0010000Increment A11000
0100110Add, A + B00011
0110110A + B + 100101
1001001A + B′01001
1011001Subtract, A + B′ + 101011
1101111Decrement A10101
1111111Transfer A10111
 
Check the subtract row:  A − B = 11 − 6 = 5
        1011        A
      + 1001        B′
      +    1        Cin
      ------
      1 0101        Cout = 1, D = 0101 = 5  ✓

    Check the decrement row:  A + 1111 = A − 1
        1011 + 1111 = 1 1010   →  D = 1010 = 10  ✓

Answer: as in the table. For unsigned subtraction, Cout = 1 means A ≥ B (no borrow). Decrement and the last transfer row also give Cout = 1; that carry is ignored.

Solved Problems — Logic and Shift Microoperations

Problem 3: Selective set, complement, clear, mask and insert

(a) A = 1101 0110 and B = 0011 1100. Find A after selective set, selective complement, selective clear and mask (each starting from the same A). (b) A = 0110 1010. Insert the value 1001 into the upper four bits of A without changing the lower four.

(a) A        = 1101 0110
        B        = 0011 1100

    Selective set        A ∨ B   = 1111 1110
    Selective complement A ⊕ B   = 1110 1010
    Selective clear      A ∧ B′  = 1100 0010    (B′ = 1100 0011)
    Mask                 A ∧ B   = 0001 0100

    (b) Step 1 — mask the upper field:
        A ← A ∧ 0000 1111   = 0000 1010
        Step 2 — OR in the new value:
        A ← A ∨ 1001 0000   = 1001 1010

Answer: (a) 1111 1110, 1110 1010, 1100 0010, 0001 0100. (b) A = 1001 1010. Read each result against B: only the bit positions where B = 1 are set, flipped or cleared; the mask keeps only those positions.

Problem 4: Shift microoperations and arithmetic-shift overflow

R = 1100 1011. Find R after each of shl, shr, cil, cir, ashl and ashr (each from the same R). Then apply ashl a second time to the ashl result and check for overflow.

R      = 1100 1011     (signed: −53)

    shl R  = 1001 0110     0 enters on the right
    shr R  = 0110 0101     0 enters on the left
    cil R  = 1001 0111     R₇ = 1 wraps to R₀
    cir R  = 1110 0101     R₀ = 1 wraps to R₇
    ashl R = 1001 0110     Vs = R₇ ⊕ R₆ = 1 ⊕ 1 = 0 → no overflow
                           (−53 × 2 = −106 ✓)
    ashr R = 1110 0101     sign bit 1 kept (−53 / 2 → −27)

    Second ashl, on 1001 0110:
    Vs = R₇ ⊕ R₆ = 1 ⊕ 0 = 1 → overflow
    Result 0010 1100 = +44, but −106 × 2 = −212 does not fit in 8 bits

Answer: shl 1001 0110, shr 0110 0101, cil 1001 0111, cir 1110 0101, ashl 1001 0110 (no overflow), ashr 1110 0101. The second ashl overflows: the sign bit changes. Here cir and ashr give the same pattern only because R0 and R7 are both 1.

Problem 5: A trace through the arithmetic logic shift unit

The arithmetic logic shift unit is selected by S3S2S1S0 and Cin: S3S2 = 00 gives the arithmetic circuit (S1S0Cin as in Problem 2), 01 gives logic (S1S0 = 00 AND, 01 OR, 10 XOR, 11 complement A), 10 gives shr A, 11 gives shl A. With 8-bit registers, A = 96 and B = 3B, the output F is loaded back into A after each pulse (B does not change). Find A after each pulse.

PulseS3S2S1S0 Cin
10010 1
20110 0
31100 0
40011 0
50111 0
60001 1
 
B = 3B = 0011 1011 throughout

    Pulse  Code     RTL               A (binary)   A (hex)
    start                             1001 0110    96
    1      0010 1   A ← A + B′ + 1    0101 1011    5B   (Cout = 1)
    2      0110 0   A ← A ⊕ B         0110 0000    60
    3      1100 0   A ← shl A         1100 0000    C0
    4      0011 0   A ← A − 1         1011 1111    BF
    5      0111 0   A ← A′            0100 0000    40
    6      0001 1   A ← A + B + 1     0111 1100    7C

    Check pulse 1: 96 − 3B = 150 − 59 = 91 = 5B  ✓
    Check pulse 6: 40 + 3B + 1 = 64 + 59 + 1 = 124 = 7C  ✓

Answer: A = 5B, 60, C0, BF, 40, 7C after pulses 1 to 6. For logic and shift codes the Cin bit has no effect.

Practice Problems

Q1. R = 1110 0101. Apply ashl repeatedly. On which shift does overflow first occur?

Show answer

1st: Vs = 1 ⊕ 1 = 0, R = 1100 1010. 2nd: Vs = 1 ⊕ 1 = 0, R = 1001 0100. 3rd: Vs = 1 ⊕ 0 = 1 → overflow on the third shift (R becomes 0010 1000).

Q2. For the arithmetic logic shift unit with A = 5C and B = E3 (8 bits), find F for the codes 0010 1, 0101 0, 1000 0 and 0001 0.

Show answer

0010 1: A − B = 79 with Cout = 0 (A < B, so a borrow). 0101 0: A ∨ B = FF. 1000 0: shr A = 2E. 0001 0: A + B = 3F with Cout = 1.

Q3. A = A7. Which logic microoperation and which B flip only the lower four bits of A? What is the result?

Show answer

Selective complement, A ← A ⊕ B with B = 0F. Result: 1010 0111 ⊕ 0000 1111 = 1010 1000 = A8.

Q4. On the four-register bus of Problem 1, give S1S0 and the load inputs for B ← A, D ← A in one pulse. Can C ← D and A ← B be done in the same pulse?

Show answer

S1S0 = 00 with the loads of B and D set to 1. No — the two transfers need different sources (D and B), and the bus carries only one source per pulse; they need two pulses.

Common Pitfalls

  • Using a value written in the same pulse. All transfers in one pulse read the registers as they were before the clock edge.
  • Testing ashl overflow after the shift. Vs = Rn−1 ⊕ Rn−2 uses the two leftmost bits before shifting.
  • Treating ashr as shr. ashr copies the sign bit into the vacated position; shr always inserts 0.
  • Forgetting Cin in subtraction. A + B′ alone is A − B − 1; subtraction needs Cin = 1.
  • Selective clear with B instead of B′. Selective clear is A ∧ B′; A ∧ B is the mask.
  • Inserting without masking first. OR alone cannot change a 1 back to 0; clear the field, then OR in the new bits.
