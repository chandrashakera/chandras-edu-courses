Shift Micro-operations

⏱ 16 min read 📝 Quiz inside 📖 Mano, Ch. 4

A shift micro-operation moves every bit of a register one position left or right in a single clock cycle. The three variants — logical, circular, and arithmetic — are identical in which way the bits move; they differ only in what value fills the vacated bit at the far end.

Logical Shift

The simplest case: a 0 always fills the vacated position, and whatever bit falls off the other end is simply discarded.

b3b2b1b0
Before (R = 1100)1100
After shr (shift right)0110

The rightmost bit (0) is lost, and a fresh 0 (highlighted) enters at b3. Logical shifts are the right choice whenever the register holds unsigned data with no sign bit to protect.

Circular Shift (Rotate)

Instead of discarding the bit that falls off, feed it back in at the other end — no information is ever lost, the whole register just rotates in place.

b3b2b1b0
Before (R = 1011)1011
After cir (circular right)1101

b0's original value (1) is exactly what reappears at b3 (highlighted) — nothing is discarded, unlike the logical case.

Arithmetic Shift

Arithmetic shift treats the register as a signed 2's-complement number. Arithmetic right shift fills the vacated bit with a copy of the sign bit instead of a plain 0 — this is what correctly implements "divide by 2" for negative numbers:

b3 (sign)b2b1b0
Before (R = 1001, i.e. −7)1001
After ashr1100

1100₂ = −4, and −7 ÷ 2 rounded toward −∞ is indeed −4 — a plain logical shift (filling with 0) would have wrongly turned a negative number positive. Arithmetic left shift, by contrast, uses exactly the same mechanics as a logical left shift (0 fills in at the bottom) — the only difference is that arithmetic left shift is defined to represent "multiply by 2," which means it must additionally be checked for overflow: if the sign bit changes value as a direct result of the shift, the result no longer fits and the multiply has overflowed.

A Combinational Shifter

A register doesn't need to be physically wired as a shift register (Unit 2) to support a shift micro-operation — a purely combinational shifter, built from one 2-to-1 multiplexer per bit position, works just as well and is what actually feeds a CPU's ALU:

One 2-to-1 MUX per bit position, repeated across the whole register — one shared Select line chooses "pass straight through" vs. "take the neighboring bit" for every position simultaneously.

An n-bit combinational shifter is just n of these MUXes side by side, all driven by the same select signal — the entire shift happens in one gate delay, with no clock edge needed at all (only the register that eventually stores the shifted result needs a clock, exactly as in the Register Transfer topic).

Common Pitfalls

  • Assuming arithmetic and logical left shift are different operations. They compute the identical bit pattern (0 fills the bottom either way) — arithmetic left shift is only distinguished by the overflow check applied to its result, not by any difference in the shift mechanics itself.
  • Using a logical shift where an arithmetic shift was needed. Logical-shifting a negative number right silently corrupts its sign, since it fills with 0 instead of duplicating the sign bit — a classic, easy-to-miss bug when writing low-level signed-division code.
  • Forgetting circular shift never loses data. Since the departing bit always reappears at the other end, n circular shifts in the same direction always return a register to its exact original value — a useful property to check your implementation against.

Applications

  • Fast multiplication/division by powers of two is implemented directly as arithmetic shifts — far cheaper in hardware than a general multiplier or divider circuit (covered later in this course).
  • Cryptographic algorithms (many hash functions and ciphers) rely heavily on circular shifts specifically because they're lossless and reversible, mixing bits without discarding any entropy.
  • Serial-to-parallel and parallel-to-serial conversion (Unit 2's shift registers) is the sequential, one-bit-per-cycle cousin of the combinational shifter introduced here — same underlying idea, different hardware tradeoff.
