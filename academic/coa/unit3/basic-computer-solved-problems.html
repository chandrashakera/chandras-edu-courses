Basic Computer Instructions — Solved Problems

⏱ 35 min read 📌 Supplementary — beyond the syllabus

The most common Unit 3 exam question gives you register and memory contents, then asks what they become after an instruction, a few instructions, or each timing signal. This page solves every pattern for the basic computer: decoding instruction words, the register-reference and memory-reference instructions from a given starting state, a T0–T5 trace of an indirect instruction, a loop, a subroutine call and return, and the interrupt cycle. All answers were checked with a register-level simulation of the basic computer.

In simple terms

Every instruction starts the same way: T0 copies PC into AR, T1 reads the instruction into IR and adds 1 to PC, T2 decodes it and puts the address part into AR. Only after that does the instruction do its own work. So when you trace, first write the fetch steps, then the execute steps — and remember that PC already points to the next instruction before execution begins.

Quick Reference

The basic computer has 4096 words of 16 bits. AR and PC are 12 bits; DR, AC, IR and TR are 16 bits; E is the carry flip-flop. All values below are hexadecimal: addresses have 3 digits, words have 4.

Solved Problems — Decoding and Single Instructions

Problem 1: Decode instruction words

Identify the type, the I bit, the operation and the address part of each word: 2A5F, B1C4, E123, 7040, 7008, F080.

Bits:  15 | 14 13 12 | 11 ... 0
            I |  opcode  | address (or operation bits)

    2A5F = 0010 1010 0101 1111
           I = 0, opcode 010 → LDA, address A5F       LDA A5F   (direct)
    B1C4 = 1011 0001 1100 0100
           I = 1, opcode 011 → STA, address 1C4       STA 1C4 I (indirect)
    E123 = 1110 0001 0010 0011
           I = 1, opcode 110 → ISZ, address 123       ISZ 123 I (indirect)
    7040 = 0111 0000 0100 0000
           opcode 111, I = 0 → register reference, bit 6 → CIL
    7008 = 0111 0000 0000 1000
           opcode 111, I = 0 → register reference, bit 3 → SNA
    F080 = 1111 0000 1000 0000
           opcode 111, I = 1 → input-output, bit 7 → ION

Answer: LDA A5F, STA 1C4 I, ISZ 123 I, CIL, SNA, ION. Opcode 111 never names a memory-reference instruction: the I bit then separates register-reference (I = 0) from input-output (I = 1).

Solved Problems — Timing-Step and Program Traces

Problem 4: T0–T5 trace of an indirect ADD

PC = 0C4, AC = 8E15, E = 0. Memory: M[0C4] = 92B0, M[2B0] = 0731, M[731] = 4F2C. Show the microoperations and the contents of AR, PC, DR, IR, AC and E at the end of each timing signal.

Step  Microoperation        AR   PC   DR    IR    AC    E
    T₀    AR ← PC               0C4  0C4  0000  —     8E15  0
    T₁    IR ← M[AR], PC ← PC+1 0C4  0C5  0000  92B0  8E15  0
    T₂    decode: D₁, I = 1     2B0  0C5  0000  92B0  8E15  0
          AR ← IR(0–11)
    T₃    D₇′IT₃: AR ← M[AR]    731  0C5  0000  92B0  8E15  0
    T₄    D₁T₄: DR ← M[AR]      731  0C5  4F2C  92B0  8E15  0
    T₅    D₁T₅: AC ← AC + DR    731  0C5  4F2C  92B0  DD41  0
          E ← Cout, SC ← 0

    Check: 8E15 + 4F2C = DD41, no carry out → E = 0

Answer: the instruction is ADD 2B0 I. The address part 2B0 holds the effective address 731; the operand 4F2C is added, giving AC = DD41, E = 0, PC = 0C5. It takes six timing signals (T0–T5).

Problem 7: The interrupt cycle

IEN = 1. The instruction INC at address 2C7 is executing when an input character arrives and FGI becomes 1. Memory word 001 holds BUN 0A0 (40A0). Find what happens after INC completes: the steps of the interrupt cycle, M[0], PC, IEN, and the next instruction fetched.

During INC (T₃): T₀′T₁′T₂′(IEN)(FGI + FGO) = 1  →  R ← 1
    INC completes: PC = 2C8 (next instruction), SC ← 0

    R = 1, so the interrupt cycle runs instead of a fetch:
    Step  Microoperations                   AR   TR    PC
    RT₀   AR ← 0, TR ← PC                   000  02C8  2C8
    RT₁   M[AR] ← TR, PC ← 0                000  02C8  000
    RT₂   PC ← PC + 1, IEN ← 0, R ← 0,      000  02C8  001
          SC ← 0

    M[0] = 02C8 (return address), IEN = 0
    Next fetch from 001: BUN 0A0  →  PC = 0A0 (service routine)

    Return, at the end of the service routine:
    ION         IEN ← 1
    BUN 0 I     PC ← M[0] = 2C8   (the interrupted program resumes)

Answer: the interrupt cycle stores 02C8 in M[0], sets PC = 001, and clears IEN and R. The instruction at 001 branches to the service routine at 0A0. The routine ends with ION and BUN 0 I, which returns to 2C8. IEN = 0 during the routine prevents a second interrupt until ION.

Practice Problems

Q1. AC = 8001, E = 0. Find AC and E after each instruction of the sequence CIL, CIL, CME, CIR.

Show answer

CIL: AC = 0002, E = 1. CIL: AC = 0005, E = 0. CME: AC = 0005, E = 1. CIR: AC = 8002, E = 1.

Q2. The instruction at address 040 is ISZ 0F2 (60F2), and M[0F2] = FFFF. Find M[0F2] and PC after execution.

Show answer

DR = FFFF + 1 = 0000, so M[0F2] = 0000 and the next instruction is skipped: PC = 041 + 1 = 042.

Q3. PC = 07E, AC = 3C3C, M[07E] = B1A0, M[1A0] = 0425. Give AR and PC at the end of T0 to T4, and the memory word that changes.

Show answer

STA 1A0 I. T0: AR = 07E, PC = 07E. T1: AR = 07E, PC = 07F. T2: AR = 1A0. T3: AR = 425. T4: M[425] ← AC, so M[425] = 3C3C; PC stays 07F. Five timing signals.

Q4. M[0A0] = 0035, M[0A1] = 0050, E = 0. Starting at 020, the program is LDA 0A0, CMA, INC, ADD 0A1, STA 0A2, HLT. Find M[0A2], E and the clock cycles used.

Show answer

CMA and INC form −0035 = FFCB; FFCB + 0050 = 1 001B. M[0A2] = 001B (= 0050 − 0035), E = 1 (no borrow). Cycles: 6 + 4 + 4 + 6 + 5 + 4 = 29.

Common Pitfalls

  • Forgetting that PC was incremented at T1. BSA stores the address of the next instruction, and a skip adds one more to an already-incremented PC.
  • Leaving AR at the old address after a register-reference instruction. T2 always loads AR ← IR(0–11), so CLA leaves AR = 800.
  • Fetching the operand from the address part of an indirect instruction. With I = 1, T3 replaces AR with the effective address first; the operand is read at T4.
  • Loading AC at T4 in LDA. T4 reads memory into DR; AC ← DR happens at T5.
  • Changing E in the wrong instructions. Only ADD, CLE, CME, CIR and CIL change E; CLA, AND and LDA leave it alone.
  • Using the stored return address as the subroutine's start. BSA starts execution one word after the address it stores into.
  • Returning from an interrupt without ION. RT2 clears IEN; the service routine must set it again before BUN 0 I.
