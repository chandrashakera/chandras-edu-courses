Associative Memory

⏱ 18 min read 📝 Quiz inside

Many data-processing tasks require searching a table in memory for a matching item — looking up a symbol table, verifying an account number, or finding a cache block. Ordinary RAM searches sequentially, one word at a time. Associative memory (also called content-addressable memory, CAM) resolves this by searching all words simultaneously in hardware (§12-4).

Basic Concept

In a standard RAM, you supply an address to retrieve a word. In an associative memory, you supply a data pattern (the argument) and the hardware compares it with every stored word in parallel. Words that match are flagged in the match register. Reading is then done by addressing only those words whose match bit is set.

Because of the added comparison logic in every cell, associative memory is more expensive per bit than RAM. It is used in applications where the search time is critical — for example, in cache tag arrays and TLBs (translation look-aside buffers).

Block Diagram

Block diagram of associative memory. Adapted from M. Morris Mano, Computer System Architecture, Fig. 12-6.

The hardware consists of four parts:

  • Argument register A (n bits) — holds the search pattern.
  • Key register K (n bits) — a mask: K_j = 1 means bit position j is compared; K_j = 0 means it is a don't-care (ignored). When K = all 1s the entire argument is compared.
  • Memory array (m words × n bits) — the CAM cells, each containing a storage flip-flop and comparison logic.
  • Match register M (m bits) — one bit per word. M_i = 1 if word i matched all unmasked argument bits; M_i = 0 otherwise.

Cell Array

Figure 12-7 shows the organisation of the m × n cell array. Cell C_ij stores bit j of word i. Each row of cells produces one bit M_i in the match register. All n cells in a row contribute to a single AND result.

Cell Logic and Match Equations

The internal logic of a typical cell C_ij (Fig 12-8) contains a flip-flop F_ij for storage, plus circuitry for read, write, and match. The match logic compares A_j with F_ij only when K_j = 1.

The equality check for one bit position j is:

x_j = A_j F_ij + A_j' F_ij'   (1 if A_j equals F_ij; 0 otherwise)

Including the key mask (to make K_j = 0 a don't-care):

term_j = x_j + K_j'   (if K_j = 0 → K_j' = 1 → term = 1, so bit j is ignored)

Word i matches if and only if all n terms equal 1:

M_i = (x₁ + K₁')(x₂ + K₂') ⋯ (xₙ + Kₙ')

Numerical Example

Suppose A = 101 111100 and K = 111 000000. Only the three leftmost bits are compared (K_j = 1 for j = 1,2,3; K_j = 0 for the rest):

Word 1100 111100100 ≠ 101 → no match0
Word 2101 000001101 = 101 → match1

Read and Write Operations

Read: after a search, M indicates which words matched. If only one word matched (M_i = 1 for exactly one i), its data is connected to the output automatically. If multiple words matched, they are read sequentially by applying a read signal to each matched word line.

Write: new information can be written by addressing each location sequentially (making the device act as a RAM for writing) or by scanning the tag register to find an unused location (tag bit = 0) and writing there.

Summary

  • Associative (content-addressable) memory is accessed by data content, not address.
  • All m words are compared with argument A in parallel — O(1) search time regardless of m.
  • Key register K masks don't-care bit positions (K_j = 0 → bit j is excluded from comparison).
  • Match register M: M_i = 1 if word i matched all unmasked bits.
  • Match logic: M_i = ∏_j (x_j + K_j') where x_j = A_j F_ij + A_j' F_ij'.
  • More expensive per bit than RAM due to comparison gates in every cell; used where search speed is critical.
