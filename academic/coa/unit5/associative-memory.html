Associative Memory

⏱ 18 min read 📝 Quiz inside

Many data-processing tasks require searching a table in memory for a matching item — looking up a symbol table, verifying an account number, or finding a cache block. Ordinary RAM searches sequentially, one word at a time. Associative memory (also called content-addressable memory, CAM) resolves this by searching all words simultaneously in hardware.

In simple terms: a normal memory is asked 'what is at address 25?'. An associative memory is asked 'where is the word that looks like this?' — and checks every word at the same time.

Basic Concept

In a standard RAM, you supply an address to retrieve a word. In an associative memory, you supply a data pattern (the argument) and the hardware compares it with every stored word in parallel. Words that match are flagged in the match register. Reading is then done by addressing only those words whose match bit is set.

Because of the added comparison logic in every cell, associative memory is more expensive per bit than RAM. It is used in applications where the search time is critical — for example, in cache tag arrays and TLBs (translation look-aside buffers).

Block Diagram

Block diagram of associative memory. Adapted from M. Morris Mano, Computer System Architecture, Fig. 12-6.

The hardware consists of four parts:

  • Argument register A (n bits) — holds the search pattern.
  • Key register K (n bits) — a mask: Kj = 1 means bit position j is compared; Kj = 0 means it is a don't-care (ignored). When K = all 1s the entire argument is compared.
  • Memory array (m words × n bits) — the CAM cells, each containing a storage flip-flop and comparison logic.
  • Match register M (m bits) — one bit per word. Mi = 1 if word i matched all unmasked argument bits; Mi = 0 otherwise.

Cell Logic and Match Equations

The internal logic of a typical cell Cij contains a flip-flop Fij for storage, plus circuitry for read, write, and match. The match logic compares Aj with Fij only when Kj = 1.

The equality check for one bit position j is:

xj = Aj Fij + Aj' Fij'   (1 if Aj equals Fij; 0 otherwise)

Including the key mask (to make Kj = 0 a don't-care):

termj = xj + Kj'   (if Kj = 0 → Kj' = 1 → term = 1, so bit j is ignored)

Word i matches if and only if all n terms equal 1:

Mi = (x₁ + K₁')(x₂ + K₂') ⋯ (xₙ + Kₙ')

Numerical Example

Suppose A = 101 111100 and K = 111 000000. Only the three leftmost bits are compared (Kj = 1 for j = 1,2,3; Kj = 0 for the rest):

Word 1100 111100100 ≠ 101 → no match0
Word 2101 000001101 = 101 → match1

Read and Write Operations

Read: after a search, M indicates which words matched. If only one word matched (Mi = 1 for exactly one i), its data is connected to the output automatically. If multiple words matched, they are read sequentially by applying a read signal to each matched word line.

Write: new information can be written by addressing each location sequentially (making the device act as a RAM for writing) or by scanning the tag register to find an unused location (tag bit = 0) and writing there.

Summary

  • Associative (content-addressable) memory is accessed by data content, not address.
  • All m words are compared with argument A in parallel — O(1) search time regardless of m.
  • Key register K masks don't-care bit positions (Kj = 0 → bit j is excluded from comparison).
  • Match register M: Mi = 1 if word i matched all unmasked bits.
  • Match logic: Mi = ∏j (xj + Kj') where xj = Aj Fij + Aj' Fij'.
  • More expensive per bit than RAM due to comparison gates in every cell; used where search speed is critical.
