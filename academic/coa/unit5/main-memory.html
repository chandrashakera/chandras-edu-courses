Main Memory

⏱ 15 min read 📝 Quiz inside

The main memory is the central storage unit that communicates directly with the CPU. It is built from semiconductor integrated circuit chips — primarily RAM and ROM — and is large enough to hold the programs and data currently being executed (§12-2).

RAM — Random Access Memory

Most of main memory is RAM, available in two technologies:

  • Static RAM (SRAM) — stores each bit in a flip-flop. Data is stable as long as power is supplied. Faster and easier to use but occupies more silicon area per bit.
  • Dynamic RAM (DRAM) — stores each bit as charge on a MOS capacitor. The charge leaks away and must be refreshed (rewritten) every few milliseconds. DRAM offers higher density and lower power per bit but requires refresh circuitry.

RAM is volatile — its contents are lost when power is removed. It is used for programs and data that change during computer operation.

ROM — Read-Only Memory

A portion of main memory is constructed from ROM chips. ROM is non-volatile — it retains its contents when power is off. It stores programs that must always be present: the bootstrap loader (the initial program that starts the operating system when power is applied), firmware, and tables of constants that do not change.

The CPU sets its program counter to the bootstrap loader address at power-on. The bootstrap loads the OS from disk into RAM, then transfers control to the OS.

RAM and ROM Chip Structure — Fig 12-2 and 12-3

A typical RAM chip (Fig 12-2) contains an array of memory cells, a bidirectional data bus, and control inputs: Chip Select 1 (CS1), Chip Select 2 (CS2̄), Read (RD), Write (WR), and an address input. The chip is active only when CS1 = 1 and CS2̄ = 0. Three-state bus buffers allow multiple chips to share the same data bus.

A ROM chip (Fig 12-3) is organised similarly but has no WR input — the data bus is output-only. For the same chip area, a ROM can hold more bits than a RAM because the internal cells are simpler.

Connecting Memory Chips to the CPU — Fig 12-4

The seven low-order address lines (A1–A7) go to each RAM chip to select one of 128 bytes within the chip. A 2×4 decoder driven by lines A8 and A9 selects which of the four RAM chips is active (when A10 = 0). Line A10 distinguishes RAM from ROM: when A10 = 0 the decoder enables one RAM chip; when A10 = 1 the ROM chip-select inputs are active.

All chips share the same bidirectional 8-bit data bus. Three-state buffers ensure only the selected chip drives the bus at any time.

Design rule: in any valid address, exactly one chip must be selected (CS enabled) and all others must be in high-impedance state. The memory address map guarantees this by partitioning the address space so no two ranges overlap.

Summary

  • SRAM: flip-flop storage, no refresh needed, faster, more area per bit.
  • DRAM: capacitor storage, must refresh every few ms, higher density, lower power.
  • ROM: non-volatile, stores bootstrap loader and firmware; no WR input.
  • Memory address map: assigns a hex range to each chip; ensures each address selects exactly one chip.
  • Chip selection uses low-order lines for intra-chip address, higher-order lines + decoders + CS inputs for inter-chip selection.
