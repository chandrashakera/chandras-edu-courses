Input-Output Interface

⏱ 15 min read 📝 Quiz inside

Every computer must communicate with the outside world — keyboards, displays, disks, printers, and other peripherals. The input-output interface is the hardware layer that makes this communication possible, resolving the fundamental differences between the CPU and peripheral devices.

Why an Interface Is Needed

Peripherals differ from the CPU in four important ways (§11-2):

  1. Signal type — peripherals are electromechanical or electromagnetic; the CPU is purely electronic. Signal levels may need conversion.
  2. Speed — peripherals are far slower than the CPU. A synchronisation mechanism is needed so neither side loses data.
  3. Data codes — peripherals may use different word lengths or encoding (e.g. 7-bit ASCII in an 8-bit byte).
  4. Operating modes — each peripheral has its own command set and must be controlled without disturbing other attached devices.

To handle these differences, each peripheral has a dedicated interface unit that sits between the CPU bus and the device controller.

The I/O Bus — Fig 11-1

A typical system connects the CPU to several peripherals through a shared I/O bus consisting of data lines, address lines, and control lines. Each peripheral has its own interface that monitors the address lines and activates when its assigned address appears on the bus.

Four Types of I/O Command

When the CPU selects an interface, it sends a function code on the control lines specifying one of four commands:

  • Control command — activates the peripheral and sets its operating mode (e.g. rewind tape, set baud rate).
  • Status command — reads the status register to check whether the device is ready or whether errors have occurred.
  • Data output command — transfers data from the CPU data bus into an interface buffer register, for the peripheral to collect.
  • Data input command — reads data from an interface buffer register (filled by the peripheral) onto the CPU data bus.

Isolated vs Memory-Mapped I/O

There are two ways to assign addresses to interface registers:

  • Isolated I/O — separate address spaces for memory and I/O, selected by dedicated I/O read and I/O write control lines. The CPU uses distinct IN/OUT instructions. Memory addresses and I/O addresses cannot clash.
  • Memory-mapped I/O — interface registers occupy part of the normal memory address space. The CPU uses ordinary load and store instructions to access them — no special I/O instructions needed. More flexible but reduces the memory address range available.
Advantage of memory-mapped I/O: all memory-reference instructions (AND, OR, shift, compare…) can operate directly on I/O data, giving the programmer a richer instruction set for controlling devices.

Summary

  • Interfaces resolve four CPU-peripheral differences: signal type, speed, data code, and operating mode.
  • The I/O bus carries data, address, and control lines shared by all interface units.
  • Four I/O command types: control, status, data output, data input.
  • Isolated I/O: separate address space, dedicated IN/OUT instructions. Memory-mapped I/O: shared address space, any memory instruction works on I/O.
  • A typical interface chip contains port registers, a control register, and a status register, selected by chip-select and register-select lines.
