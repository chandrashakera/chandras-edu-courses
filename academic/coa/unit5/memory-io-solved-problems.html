Memory and I/O — Solved Problems

⏱ 30 min read 📌 Supplementary — beyond the syllabus
In simple terms: most memory and I/O numericals reduce to powers of two (how many locations, how many lines, how many chips) or to time × count (how long a transfer takes and how much of it the CPU loses).

These problems go one step beyond the worked examples on the Main Memory, Priority Interrupt and Direct Memory Access pages, in the form they usually appear in exams: chip counts and memory maps, disk timing, interrupt priority and DMA transfer time.

Key Formulas

Locations = 2ⁿ for n address lines        n = log₂(locations)
Chips     = (total words ÷ chip words) × (total width ÷ chip width)
Size of an address range = last − first + 1
Disk access time = seek + average rotational latency (½ revolution) + transfer
CPU or memory time lost per second = events per second × time per event

Address lines are numbered from A1, as on the Main Memory page. Many exam papers number them from A0; the wiring is the same, only the labels shift by one.

1. Memory Chips and Address Space

Problem 1 — Address and Data Lines

Reverse: 24 address lines and 32 data lines → 2²⁴ = 16M words × 4 bytes = 64 MB
Byte- vs word-addressable: a 4 GB memory needs 32 lines if every byte has an address,
but only 30 lines if each address is a 32-bit (4-byte) word (4G ÷ 4 = 1G = 2³⁰ words).

Problem 2 — Chip Count and Decoder: 32K × 16 from 2K × 8 Chips

Chips = (32K ÷ 2K) × (16 ÷ 8) = 16 × 2 = 32 chips → 16 rows of 2 chips side by side
Address lines: 32K = 2¹⁵ → 15 lines
Each chip: 2K = 2¹¹ → the low 11 lines (A1–A11) go to every chip
Row select: the top 4 lines (A12–A15) drive a 4-to-16 decoder, one output per row
Data: each row's two chips supply bits 15–8 and 7–0

Problem 3 — Memory Address Map: 2 KB RAM + 2 KB ROM on a 12-bit Address Bus

The RAM is built from 512 × 8 chips; the ROM is one 2K × 8 chip. Place RAM at the bottom of the 4K address space and ROM at the top.

ComponentAddress range (hex)A12A11 A10A9 … A1

RAM 2200H – 3FFH00 1x x x x x x x x x
RAM 3400H – 5FFH01 0x x x x x x x x x
RAM 4600H – 7FFH01 1x x x x x x x x x

RAM: 2K ÷ 512 = 4 chips; each uses A1–A9 (512 = 2⁹)
     A10, A11 → 2-to-4 decoder that selects one RAM chip; decoder enabled only when A12 = 0
ROM: 2K = 2¹¹ → uses A1–A11; selected when A12 = 1
Check: address 5A3H = 0101 1010 0011 → A12 = 0, A11 A10 = 10 → RAM 3 ✓

Problem 4 — Size from an Address Range

A chip occupies 4000H – 5FFFH.
Size = 5FFFH − 4000H + 1 = 2000H = 8192 = 8K locations → 13 address lines
Chip select: 4000H = 010 0 0000 0000 0000, 5FFFH = 010 1 1111 1111 1111
            → the top three lines A16 A15 A14 = 010 select it
A 4K chip starting at C000H ends at C000H + FFFH = CFFFH.

Problem 5 — Disk Access Time

A disk rotates at 6000 rpm, has 64 sectors of 512 bytes per track and an average seek time of 6 ms. Find the time to read one sector and the transfer rate.

One revolution        = 60 s ÷ 6000 = 10 ms
Avg rotational latency = ½ × 10 ms = 5 ms
One sector passes the head in 10 ms ÷ 64 = 0.15625 ms
Access time for one sector = 6 + 5 + 0.156 ≈ 11.16 ms
Transfer rate = bytes per track ÷ time per revolution = (64 × 512) ÷ 10 ms
              = 32,768 bytes ÷ 0.01 s = 3,276,800 bytes/s ≈ 3.28 MB/s

Seek and latency dominate: reading the sector itself takes under 2 % of the access time.

2. Interrupt Priority

Problem 6 — Daisy-Chain Priority

Four devices are daisy-chained, D1 nearest the CPU (highest priority). D2 and D4 request an interrupt at the same time. Trace the acknowledge (PI = priority in, PO = priority out).

DeviceRequesting?PIPOAction
D1No1 (INTACK)1Passes the acknowledge on
D2Yes10Places its vector address (VAD) on the bus — serviced
D3No00Blocked
D4Yes00Waits; its request stays pending

After D2’s routine finishes and D2 drops its request, the interrupt line is still active because of D4, so the next acknowledge passes through D1–D3 and D4 is serviced.

Problem 7 — Parallel Priority with Mask Register

Interrupt register I0 I1 I2 I3 = 0 1 1 1 (I0 highest priority); mask register = 1 0 1 1; IEN = 1.

Effective requests = interrupt AND mask = 0111 AND 1011 = 0011 → I2 and I3
Priority encoder (I0 highest):  x = I0′I1′,  y = I0′I1 + I0′I2′
   x = 1·1 = 1,  y = 0 + 1·0 = 0  → xy = 10 → I2 is serviced
IST = 1 (at least one unmasked request) and IEN = 1 → the CPU is interrupted
I1 is pending but masked; I3 is serviced after I2 is cleared.

Problem 8 — CPU Cost of Interrupt-Driven I/O vs DMA

A device delivers 20,000 bytes/s.

Interrupt I/O: one interrupt per byte, 10 µs per service routine
   CPU time lost = 20,000 × 10 µs = 0.2 s per second → 20 % of the CPU
DMA: blocks of 1,000 bytes; the CPU spends 20 µs per block (set-up + end interrupt)
   Blocks per second = 20,000 ÷ 1,000 = 20
   CPU time lost = 20 × 20 µs = 400 µs per second → 0.04 % of the CPU

DMA still uses 20,000 memory cycles per second, but the CPU no longer runs code for each byte.

3. DMA Transfer Time

Problem 9 — Burst Transfer of a Block

A DMA controller moves an 8 KB block into a 16-bit-wide memory (one word per memory cycle of 0.2 µs) in burst mode. The CPU spends 10 µs setting up the controller and 15 µs servicing the end-of-transfer interrupt.

Words = 8 KB ÷ 2 bytes = 8192 ÷ 2 = 4096 words
Burst time = 4096 × 0.2 µs = 819.2 µs  — the CPU cannot use the bus for this whole time
Start to finish = 10 + 819.2 + 15 = 844.2 µs
CPU work = 10 + 15 = 25 µs (instead of running a 4096-iteration transfer loop)

Problem 10 — Cycle Stealing: Fraction of Memory Cycles Taken

A device supplies 1 MB/s (one byte every 1 µs); the DMA steals one 100 ns memory cycle per byte.

Fraction of memory cycles stolen = 100 ns ÷ 1 µs = 0.1 → 10 %
An 8 KB block takes 8192 × 1 µs = 8.192 ms — set by the device, not the memory
The CPU runs between steals and is delayed only when it needs memory in a stolen cycle.

Problem 11 — DMA Register Widths

Memory of 64K words → address register = 16 bits (2¹⁶ = 64K)
Largest block 4,000 words → word count register = 12 bits (2¹² = 4096 ≥ 4000)

Practice Problems

  1. How many 256 × 4 chips build a 4K × 8 memory, and what decoder selects the rows?
    Show answer

    (4K ÷ 256) × (8 ÷ 4) = 16 × 2 = 32 chips in 16 rows; 12 address lines, 8 to every chip, 4 to a 4-to-16 decoder.

  2. A 16K × 8 memory starts at 8000H. What is its last address?
    Show answer

    8000H + 3FFFH = BFFFH.

  3. Find the average rotational latency of a 7200 rpm disk.
    Show answer

    60 s ÷ 7200 = 8.33 ms per revolution → 4.17 ms.

  4. Five devices are daisy-chained (D1 highest); D3 and D5 request together. Which is serviced, and what are D3’s PI and PO?
    Show answer

    D3; PI = 1, PO = 0. D4 and D5 receive PI = 0.

  5. Interrupt register I0–I3 = 1100, mask = 0111. Which request is serviced, and what is xy?
    Show answer

    Effective 0100 → I1; xy = 01.

  6. A 2 KB block is transferred by cycle stealing from a 500 KB/s device; each steal takes one 50 ns memory cycle. Find the transfer time and the fraction of memory cycles stolen.
    Show answer

    2048 ÷ 500,000 s = 4.096 ms; one byte every 2 µs → 50 ns ÷ 2 µs = 2.5 %.

  7. Memory has 1M words; the largest DMA block is 2,000 words. Give the address and word count register widths.
    Show answer

    20 bits and 11 bits (2¹¹ = 2048).

Common Pitfalls

  • Counting chips by capacity only — 32K × 16 from 2K × 8 is 32 chips, not 16; width and depth both multiply.
  • Off by one in address ranges — size = last − first + 1; a 4K chip at C000H ends at CFFFH, not D000H.
  • Using a full revolution as the latency — average rotational latency is half a revolution.
  • Reading the daisy chain backwards — priority falls with distance from the CPU; a requesting device sets PO = 0 and blocks everything after it.
  • Forgetting the mask — AND the interrupt register with the mask before applying priority.
  • Mixing bytes and words in DMA — convert the block to the memory’s word size before multiplying by the cycle time.
