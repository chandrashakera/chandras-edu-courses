Address Sequencing

⏱ 16 min read 📝 Quiz inside 📖 Mano, Ch. 7

A microprogram stored in control memory is not executed strictly from beginning to end. Each machine instruction maps to its own microprogram routine, those routines share a common fetch sequence, and conditional branches may take different paths depending on status bits. The hardware that computes which address to load into the CAR for the next clock cycle is the microprogram sequencer. Understanding its four capabilities is the central task of this topic.

Four Required Capabilities

Mano identifies four operations the sequencer must support:

  1. Increment the CAR — execute the next microinstruction in sequence.
  2. Unconditional or conditional branch — jump to the address in the AD field, always or only when a tested status bit has a specific value.
  3. Map the machine-instruction opcode to a control memory address — at the start of each execute phase, jump to the routine for the current machine instruction.
  4. Subroutine call and return — jump to a shared microprogram subroutine and return to the calling address afterwards.

The Sequencer Block (Fig. 7-2)

The multiplexers select one of four address sources each cycle. The incrementer adds one to the CAR value; its output also feeds the SBR during a subroutine call. The subroutine register (SBR) saves the return address. The branch logic tests the status bit selected by CD and drives the MUX select lines. The mapping logic converts the machine-instruction opcode into a control memory starting address.

The BR Field and Four Sequencing Modes

BROperation
00Continue: CAR ← CAR + 1
01Conditional branch: if CD condition true, CAR ← AD; else CAR ← CAR + 1
10Map: CAR ← mapping logic output (opcode → control address)
11Call: SBR ← CAR + 1, CAR ← AD  |  Return: CAR ← SBR

When CD = 00 (condition U, always true), a BR = 01 branch is unconditional. The mapping logic is implemented with a PLD or a small ROM that transforms opcode bits into a control memory address. Nested subroutine calls require a hardware stack in the SBR, since one register can only save one return address.

Common Pitfalls

  • Forgetting the mapping step. The correct sequence is fetch → map → execute. The sequencer cannot jump from the fetch routine to the correct execute routine without the mapping hardware.
  • Confusing BR and CD. BR selects what kind of address transition to make; CD selects which status bit to test. Both fields act together for conditional branching.
  • SBR depth. One SBR register supports only one level of subroutine nesting. A subroutine that calls another subroutine overwrites the first return address.
  • Mapping input. Mapping logic reads opcode bits from the instruction register, not from the AD field of the current microinstruction.
