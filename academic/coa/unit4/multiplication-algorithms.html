Multiplication Algorithms

⏱ 18 min read 📝 Quiz inside

Multiplication of two n-bit binary numbers produces a 2n-bit product. This topic covers three methods: the basic hardware algorithm for signed-magnitude data, Booth's algorithm for signed-2's complement numbers, and the combinational array multiplier.

In simple terms: the computer multiplies the way you do on paper — add the multiplicand when the multiplier bit is 1, then shift — but it shifts the partial product right instead of shifting the multiplicand left. Booth's method does the same for signed numbers by subtracting at the start of a run of 1s and adding at its end.

Signed-Magnitude Multiplication — Hardware

The paper-and-pencil method adds shifted copies of the multiplicand whenever the corresponding multiplier bit is 1. The hardware version adapts this: instead of shifting the multiplicand left, the partial product is shifted right after each addition. This keeps all operations within fixed-width registers.

Hardware

The figure below shows the hardware, which extends the add/subtract hardware from the Addition and Subtraction topic with a Q register to hold the multiplier.

Hardware for multiply operation. Adapted from M. Morris Mano, Computer System Architecture, Fig. 10-5.

  • B register — holds the multiplicand (magnitude).
  • A register — accumulates the partial product (magnitude); cleared to 0 initially.
  • Q register — holds the multiplier; its rightmost bit Qₙ is tested each step.
  • E flip-flop — the carry extension to the left of A; cleared to 0 initially.
  • SC (sequence counter) — counts down from n−1 to 0, controlling the loop.
  • Sign flip-flops Aₛ and Qₛ — the sign of the product is Aₛ = Qₛ ⊕ Bₛ (XOR of multiplier and multiplicand signs).

Algorithm

Flowchart for multiply operation. Adapted from M. Morris Mano, Computer System Architecture, Fig. 10-6.

Each iteration of the loop:

  1. Test Qₙ (rightmost bit of Q). If Qₙ = 1, add B to A: EA ← A + B.
  2. Shift the combined register EAQ one position to the right: shr EAQ, SC ← SC − 1.
  3. After n steps (SC = 0), the product is in AQ — A holds the most significant half and Q the least significant half.
SC is initialised to n − 1 (not n) in the multiply flowchart, because the first partial product is accumulated before the first shift, so n − 1 additional shifts complete the multiplication.

Booth Multiplication Algorithm

Booth's algorithm multiplies two signed integers in 2's complement representation directly, without converting to signed-magnitude first. It exploits the fact that a string of 1s in the multiplier can be replaced by a subtraction at the least significant end and an addition at the most significant end, reducing the number of additions.

The algorithm inspects two bits at a time — the current multiplier bit Qₙ and the previously shifted-out bit Qₙ₊₁ — and decides:

Booth algorithm — action for each bit pair
QₙQₙ₊₁ActionMeaning
10AC ← AC + B̄R + 1 (subtract BR)Beginning of a string of 1s
01AC ← AC + BR (add BR)End of a string of 1s
00No arithmetic (shift only)Middle of a string of 0s
11No arithmetic (shift only)Middle of a string of 1s

After the arithmetic operation (if any), an arithmetic shift right (ashr) is applied to AC and QR together. The arithmetic shift preserves the sign bit of AC, which is essential for correct 2's complement handling.

Booth Flowchart

Booth algorithm for multiplication of signed-2's complement numbers. Adapted from M. Morris Mano, Computer System Architecture, Fig. 10-8.

Initialisation: AC ← 0, Qₙ₊₁ ← 0, SC ← n. The loop repeats n times. On each iteration, inspect Qₙ Qₙ₊₁, perform the action from the table above, then ashr (AC & QR) and decrement SC. When SC = 0 the product is in AC and QR.

Numerical Example (n = 5)

Multiplying (−9) × (−13) = +117. In 5-bit 2's complement: BR = 10111 (−9), QR = 10011 (−13), B̄R + 1 = 01001.

Array Multiplier

The sequential algorithm requires n clock cycles. A combinational array multiplier produces the product in a single step using parallel hardware. For j multiplier bits and k multiplicand bits, the array requires j × k AND gates and (j − 1) k-bit adders to produce a product of j + k bits.

Summary

  • Sequential multiply: inspect Qₙ each cycle — if 1 add B, always shr EAQ; SC starts at n − 1; product in AQ.
  • Booth: inspect two bits Qₙ Qₙ₊₁ — 3 cases; ashr preserves sign; works directly on 2's complement; SC starts at n; product in AC and QR.
  • Array multiplier: j × k AND gates + (j − 1) k-bit adders; combinational (single cycle) but expensive in hardware.
