Data Transfer and Manipulation

⏱ 15 min read 📝 Quiz inside

A CPU's instruction set divides naturally into groups by what each instruction does to data. The textbook identifies four such groups — data transfer, arithmetic, logic and bit manipulation, and shift — and provides representative tables of mnemonics for each. Understanding these groups clarifies why an instruction set is organised the way it is and how the ALU, shifter, and registers cooperate to execute each category.

In simple terms: most instructions either move data (load, store, move) or change it (add, AND, shift). This topic lists the typical instructions in each group.

Data Transfer Instructions

Data transfer instructions move the content of one location to another without changing the value itself. The table below lists 8 typical instructions of this kind. The most common transfers are between memory and processor registers, between registers and input/output terminals, and between two processor registers.

NameMnemonicTypical action
LoadLDMemory → processor register (usually the accumulator)
StoreSTProcessor register → memory
MoveMOVRegister → register (or memory ↔ memory on some architectures)
ExchangeXCHSwap two registers, or a register and a memory word
InputINI/O terminal → processor register
OutputOUTProcessor register → I/O terminal
PushPUSHProcessor register → top of memory stack
PopPOPTop of memory stack → processor register

Typical data transfer instructions. Adapted from M. Morris Mano, Computer System Architecture, Table 8-5.

Each instruction can occur with a variety of addressing modes (covered in Topic 4.6). For instance, the load-to-accumulator instruction in immediate mode is sometimes written LDI, while some assemblers use a special prefix such as # to indicate the immediate operand. The mnemonic convention varies between architectures; the important point is that the same transfer operation may appear under different names.

Arithmetic Instructions

Arithmetic instructions perform numerical computations on operands stored in registers or memory. The table below lists 9 typical arithmetic instructions. The four basic operations — increment, decrement, add, subtract — are almost universally available. Multiply and divide may be omitted on small processors, in which case software subroutines perform them.

NameMnemonic
IncrementINC
DecrementDEC
AddADD
SubtractSUB
MultiplyMUL
DivideDIV
Add with carryADDC
Subtract with borrowSUBB
Negate (2's complement)NEG

Typical arithmetic instructions. Adapted from M. Morris Mano, Computer System Architecture, Table 8-7.

Many computers provide multiple variants of add and subtract to handle different data types — for example, ADDI for binary integers, ADDF for floating-point operands, and ADDD for BCD decimal. The add with carry instruction supports double-precision arithmetic by including the carry from a previous lower-word addition. Subtract with borrow is its counterpart. The negate instruction forms the 2's complement of a value, effectively reversing its sign when using signed representation.

Logical and Bit Manipulation Instructions

Logical instructions treat each bit of a register independently as a Boolean variable. The table below lists 10 typical logical and bit manipulation instructions. They make it possible to clear a selected bit to 0, set it to 1, or complement it, which is useful for masking, flag control, and selective complement operations.

NameMnemonicEffect
ClearCLRAll bits of operand → 0
ComplementCOM1's complement of operand
ANDANDBit-by-bit AND — used to clear selected bits (mask)
ORORBit-by-bit OR — used to set selected bits
Exclusive-ORXORBit-by-bit XOR — used to complement selected bits
Clear carryCLRCCarry flag → 0
Set carrySETCCarry flag → 1
Complement carryCOMCCarry flag ← NOT carry
Enable interruptEIInterrupt flip-flop → 1
Disable interruptDIInterrupt flip-flop → 0

Typical logical and bit manipulation instructions. Adapted from M. Morris Mano, Computer System Architecture, Table 8-8.

The AND instruction is also called a mask because ANDing a register with a pattern of 0s clears the corresponding bit positions while leaving the rest unchanged. OR sets selected bits, and XOR complements them — all without disturbing the other bits. The carry and interrupt control instructions in the table above manipulate individual flag flip-flops rather than whole registers.

Shift Instructions

Shift instructions move the bits of a register left or right by one or more positions. The table below defines 8 shift instructions covering 4 types: logical shift, arithmetic shift, rotate, and rotate-through-carry. Each type has both a left and a right variant.

NameMnemonicBit shifted in at the vacated end
Logical shift rightSHR0
Logical shift leftSHL0
Arithmetic shift rightSHRASign bit (leftmost bit preserved)
Arithmetic shift leftSHLA0 (same as logical shift left)
Rotate rightRORRightmost bit wraps to leftmost
Rotate leftROLLeftmost bit wraps to rightmost
Rotate right through carryRORCCarry bit; rightmost bit → carry
Rotate left through carryROLCCarry bit; leftmost bit → carry

Typical shift instructions. Adapted from M. Morris Mano, Computer System Architecture, Table 8-9.

A logical shift inserts 0 at the vacated end and is useful for unsigned multiplication or division by powers of 2. An arithmetic shift right preserves the sign bit to maintain the correct sign in signed 2's complement arithmetic; arithmetic shift left inserts 0 and is identical to logical shift left. Rotate instructions are circular — no bit is lost; the bit shifted out reappears at the other end. Rotate-through-carry treats the carry flag as an extra bit of the register, effectively providing a 9-bit (or 17-bit on a 16-bit machine) circular shift.

Some processors encode all shift information in a single multi-field instruction format rather than providing separate mnemonics. One such format uses five fields:

Shift instruction format. Adapted from M. Morris Mano, Computer System Architecture, §8-6.

In this format, the TYPE field is 2 bits wide, encoding the four shift variants; RL is a single bit selecting direction; and COUNT is a k-bit field allowing up to 2k − 1 positions in one instruction. With such a format a single instruction can specify the shift type, direction, and count simultaneously.

Common Pitfalls

  • Confusing logical and arithmetic right shift. A logical right shift always inserts 0, treating the operand as unsigned. An arithmetic right shift replicates the sign bit, preserving the sign in 2's complement. Applying logical right shift to a negative signed integer gives a wrong result.
  • Assuming mnemonic names are standard. The tables above list representative names; actual architectures use different mnemonics for the same operations. Always consult the specific instruction set reference.
  • Overlooking carry in multi-word shifts. Shifting a value wider than one register requires chaining shifts with RORC or ROLC so the carry correctly bridges the two words.

Key Points

  • Data transfer: the table lists 8 instructions; no arithmetic is performed — only the location of the data changes.
  • Arithmetic: the table lists 9 instructions. Multiply and divide may be absent on small processors and implemented in software.
  • Logical and bit manipulation: the table lists 10 instructions. AND clears selected bits, OR sets them, XOR complements them.
  • Shift: the table lists 8 instructions covering 4 types: logical, arithmetic, rotate, and rotate-through-carry, each with left and right variants.
  • The shift instruction field format packs type, direction, and count into one instruction using five fields: OP, REG, TYPE (2 bits), RL (1 bit), COUNT (k bits).
