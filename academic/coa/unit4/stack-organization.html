Stack Organization

⏱ 18 min read 📝 Quiz inside 📖 Mano, Ch. 8 §8-3

A stack is a last-in, first-out (LIFO) storage device where the item stored most recently is the first to be retrieved. In digital computers the stack is a memory unit paired with an address register called the stack pointer (SP), whose value always points to the top item. This topic covers the register stack hardware, the memory stack used by most CPUs, and the reverse Polish notation that makes the stack so useful for arithmetic.

Register Stack (Fig. 8-3)

A register stack is a finite collection of registers organised as a 64-word unit. The SP holds a 6-bit address (2⁶ = 64). Three one-bit registers support correct operation: SP holds the address of the top item; FULL is set to 1 when the stack contains 64 items; EMTY is set to 1 when the stack is empty. (Mano spells it EMTY, not EMPTY.) The data register DR is the channel through which all words enter and leave.

Adapted from M. Morris Mano, Computer System Architecture, Fig. 8-3

Initially SP = 0, EMTY = 1, FULL = 0. The first item pushed goes to address 1. When SP wraps around from 63 back to 0 (in 6-bit arithmetic), the stack is full.

Push and Pop RTL

Push (executed when FULL = 0):

SP ← SP + 1Increment stack pointer
M[SP] ← DRWrite item on top of stack
If (SP = 0) then (FULL ← 1)Check if stack is full
EMTY ← 0Mark stack not empty

Pop (executed when EMTY = 0):

DR ← M[SP]Read item from top of stack
SP ← SP − 1Decrement stack pointer
If (SP = 0) then (EMTY ← 1)Check if stack is empty
FULL ← 0Mark stack not full

Memory Stack (Fig. 8-4)

A memory stack dedicates a segment of main memory to stack operations and uses a processor register as the stack pointer. Three registers provide addresses to memory: PC for instructions, AR for operands, and SP for the stack.

Adapted from M. Morris Mano, Computer System Architecture, Fig. 8-4

SP is initialised to 4001. The stack grows by decreasing address: push decrements SP first, then writes to M[SP]; pop reads M[SP] first, then increments SP. The lowest usable address is 3000. Most CPUs rely on software to check stack limits using two processor registers holding the upper and lower bounds.

Reverse Polish Notation and Expression Evaluation

Infix notation places the operator between operands (A + B). Reverse Polish notation (RPN), also called postfix, places the operator after: AB+. RPN is ideally suited to stack evaluation — scan left to right; push each operand; when an operator is reached, pop the two top operands, apply the operator, and push the result. The final result remains on top of the stack.

Example: evaluate (3 × 4) + (5 × 6). In RPN: 3 4 * 5 6 * +

SymbolStack (bottom → top)Action

*12Pop 4 and 3; push 3×4 = 12

Compilers routinely convert infix to RPN before generating machine code because it is the most efficient method for translating arithmetic into machine instructions.

Common Pitfalls

  • EMTY vs EMPTY. Mano writes EMTY throughout §8-3. Using EMPTY in an exam answer is a notation mismatch.
  • Growth direction. The register stack (Fig. 8-3) grows upward — SP increments on push. The memory stack (Fig. 8-4) grows downward — SP decrements on push. The order of the two microoperations reverses accordingly.
  • Erroneous operations. Pushing when FULL = 1 or popping when EMTY = 1 produces an error. Always check the flag before the operation.
  • RPN operand order. For subtraction and division, order matters: the first operand popped is the right operand (divisor or subtrahend); the second pop gives the left operand.
