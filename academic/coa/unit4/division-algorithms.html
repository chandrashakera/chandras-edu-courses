Division Algorithms

⏱ 15 min read 📝 Quiz inside

Binary division is simpler than decimal division because each quotient digit is either 0 or 1 — there is no need to estimate how many times the divisor fits. Section 10-4 develops the hardware algorithm for signed-magnitude division.

In simple terms: the hardware divides like long division in binary. Each step shifts the partial remainder left and tries subtracting the divisor; if it fits, the quotient bit is 1, otherwise the remainder is restored and the bit is 0.

Overview

The hardware reuses the same complementer-and-adder circuit used for addition, subtraction, and multiplication. The double-length dividend is stored in registers A and Q. The divisor is in register B. At each step the hardware:

  1. Shifts the partial remainder left (shl EAQ).
  2. Subtracts B from A by adding the 2's complement: EA ← A + B̄ + 1.
  3. Tests E (the carry): if E = 1, A ≥ B — the quotient bit is 1 (Qₙ ← 1); if E = 0, A < B — restore A by adding B back and the quotient bit remains 0.
  4. Decrements SC.

After n steps the quotient is in Q and the remainder is in A.

Divide Overflow

Overflow occurs when the quotient requires more bits than the register can hold. The condition is detected before the main loop: if the high-order half of the dividend (the initial value in A) is greater than or equal to the divisor B, a quotient of more than n bits would result and a divide-overflow flip-flop DVF is set to 1. The operation is then aborted. Hardware typically generates an interrupt when DVF is set.

Divide overflow condition: DVF ← 1 when the initial E = 1 after EA ← A + B̄ + 1, meaning A ≥ B before any shift. Division by zero is also caught here because any dividend is greater than zero.

Hardware Algorithm

Flowchart for divide operation (signed-magnitude). Adapted from M. Morris Mano, Computer System Architecture, Fig. 10-13.

Reading the flowchart:

  1. Initialise: Qₛ ← Aₛ ⊕ Bₛ (sign of quotient), SC ← n − 1.
  2. Overflow check: EA ← A + B̄ + 1. If E = 1 (A ≥ B): restore A (EA ← A + B), set DVF ← 1, END (divide overflow). If E = 0 (A < B): restore A (EA ← A + B), clear DVF ← 0, enter the divide-magnitudes loop.
  3. Divide-magnitudes loop (n times):
    1. shl EAQ (shift partial remainder left, inserting next dividend bit).
    2. EA ← A + B̄ + 1 (trial subtraction).
    3. If E = 1 (A ≥ B): Qₙ ← 1. If E = 0 (A < B): restore EA ← A + B.
    4. SC ← SC − 1. If SC ≠ 0 repeat; else END.
SC is initialised to n − 1 in the divide algorithm. One extra shift (the overflow-check step) handles the first bit implicitly, so n − 1 additional iterations complete the quotient.

Summary

  • Division hardware reuses the complementer-adder from multiplication; dividend in AQ (double length), divisor in B.
  • SC ← n − 1 (the overflow check counts as one step).
  • Divide overflow: if initial A ≥ B, DVF ← 1 and the operation is aborted — hardware typically triggers an interrupt.
  • Each iteration: shl EAQ → trial subtract → test E → set Qₙ or restore A → SC − 1.
  • At the end: quotient in Q, remainder in A.
