Instruction Formats

⏱ 16 min read 📝 Quiz inside 📖 Mano, Ch. 8 §8-4

An instruction format is the binary layout of a machine instruction as it appears in memory or in a control register. The bits are divided into fields — most commonly an operation code (opcode), an address field, and a mode field. The number of address fields determines the CPU organisation and strongly influences the number of instructions a program needs to execute a given task.

Fields in an Instruction

The three standard fields are: (1) the opcode field, which specifies the operation; (2) the address field, which designates a memory address or a processor register; and (3) the mode field, which specifies how the operand or effective address is determined. Special fields exist for certain instructions — for example, a shift-count field in a shift instruction.

A register address is a k-bit field that selects one of 2k registers. For example, 16 registers require a 4-bit register address field.

Four Instruction Format Types

Most computers fall into one of three CPU organisations: single accumulator, general register, or stack. The number of explicit address fields depends on the organisation.

Adapted from M. Morris Mano, Computer System Architecture, §8-4

Evaluating X = (A+B)*(C+D) — Four Formats Compared

Operands reside in memory at A, B, C, D; result stored at X.

Three-address instructions — three instructions total:

ADD R1, A, BR1 ← M[A] + M[B]
ADD R2, C, DR2 ← M[C] + M[D]
MUL X, R1, R2M[X] ← R1 * R2

Two-address instructions — MOV needed to set up registers:

MOV R1, AR1 ← M[A]
ADD R1, BR1 ← R1 + M[B]
MOV R2, CR2 ← M[C]
ADD R2, DR2 ← R2 + M[D]
MUL R1, R2R1 ← R1 * R2
MOV X, R1M[X] ← R1

One-address instructions — all operations through implied accumulator AC:

LOAD AAC ← M[A]
ADD BAC ← AC + M[B]
STORE TM[T] ← AC
LOAD CAC ← M[C]
ADD DAC ← AC + M[D]
MUL TAC ← AC * M[T]
STORE XM[X] ← AC

Zero-address instructions — stack computer; TOS = top of stack:

PUSH ATOS ← A
PUSH BTOS ← B
ADDTOS ← (A + B)
PUSH CTOS ← C
PUSH DTOS ← D
ADDTOS ← (C + D)
MULTOS ← (C+D)*(A+B)
POP XM[X] ← TOS

Common Pitfalls

  • Confusing instruction count with instruction width. Three-address programs have fewer instructions but each instruction word is wider (more bits). Zero-address programs have more instructions but each word is narrower.
  • MOV direction. In two-address format, MOV R1, A means R1 ← M[A] — the register is the destination. Follow Mano's convention.
  • Temporary location in one-address programs. The result of A+B must be stored to T before computing C+D, because AC is overwritten by LOAD C.
  • PUSH and POP have one address. Zero-address refers only to arithmetic instructions like ADD and MUL. PUSH X and POP X still carry a memory address.
