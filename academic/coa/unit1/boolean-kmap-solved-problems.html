Boolean Simplification and K-Maps — Solved Problems

⏱ 25 min read 📌 Supplementary — beyond the syllabus
In simple terms: algebra and K-maps reach the same answer — the K-map just makes the adjacent terms you can combine visible at a glance.

These problems use Binary Logic and K-Map Representation. On every K-map below, rows are AB and columns are CD in Gray-code order (00, 01, 11, 10); X marks a don’t-care. (The consensus theorem example is on Binary Logic.)

1. Algebraic Simplification

Problem 1 — x′y′z + x′yz + xy′z

= x′z(y′ + y) + xy′z        = x′z + xy′z
= z(x′ + xy′)               = z(x′ + y′)        (x′ + xy′ = x′ + y′)
= x′z + y′z

Problem 2 — (x + y)(x + y′)

= x + yy′ = x + 0 = x       (distributive law: (x + y)(x + z) = x + yz)

Problem 3 — xy + xy′z + x′z

xy + xy′z = x(y + y′z) = x(y + z) = xy + xz
xz + x′z  = z
Result: xy + z

Problem 4 — Complement of F = x′yz′ + x′y′z (De Morgan)

F′ = (x′yz′)′ · (x′y′z)′ = (x + y′ + z)(x + y + z′)

2. Canonical Forms

Problem 5 — Express F = a′b + ab′d + c′d as a Sum of Minterms

a′b   → a′b(c + c′)(d + d′) → 0100, 0101, 0110, 0111 → m4, m5, m6, m7
ab′d  → ab′(c + c′)d        → 1001, 1011           → m9, m11
c′d   → (a + a′)(b + b′)c′d → 0001, 0101, 1001, 1101 → m1, m5, m9, m13
F = Σm(1, 4, 5, 6, 7, 9, 11, 13)      (m5 and m9 are counted once)

Problem 6 — Express F = (a + c)(b + c′) in Canonical POS

(a + c)  → (a + c + bb′) = (a + b + c)(a + b′ + c)       → M0, M2
(b + c′) → (b + c′ + aa′) = (a + b + c′)(a′ + b + c′)    → M1, M5
F = ΠM(0, 1, 2, 5) = (a + b + c)(a + b + c′)(a + b′ + c)(a′ + b + c′)
Equivalently F = Σm(3, 4, 6, 7)

3. Four-Variable K-Maps

Problem 7 — F = Σm(1, 2, 3, 4, 5, 6, 8, 13): Minimal SOP and POS

AB \ CD00011110
000111
011101
110100
101000
  • Essential groups: m5, m13 → BC′D; m8 has no adjacent 1 → AB′C′D′ (stays alone).
  • Remaining m1, m2, m3, m4, m6: pairs A′B′D (m1, m3), A′CD′ (m2, m6), A′BC′ (m4, m5).
SOP: F = BC′D + AB′C′D′ + A′B′D + A′CD′ + A′BC′

This map has four equally minimal SOP answers (e.g. A′BD′ in place of A′BC′ with A′B′D, A′CD′ kept, or A′C′D + A′B′C + A′BD′). Any one is correct — examiners accept all.

POS: F = (A′ + C′)(A + B + C + D)(A′ + B + D′)(A′ + B′ + D)(B′ + C′ + D′)

Problem 8 — F = ΠM(0, 1, 2, 3, 4, 10, 11): Minimal POS and SOP

AB \ CD00011110
000000
010111
111111
101100
  • 0-groups: row AB = 00 → (A + B); m2, m3, m10, m11 → (B + C′); m0, m4 → (A + C + D).
POS: F = (A + B)(B + C′)(A + C + D)
  • 1-groups: BD (m5, m7, m13, m15), BC (m6, m7, m14, m15), AC′ (m8, m9, m12, m13).
SOP: F = BD + BC + AC′

Problem 9 — F = ΠM(1, 3, 5, 7, 13, 15)

AB \ CD00011110
001001
011001
111001
101111
  • 0-groups: m1, m3, m5, m7 → (A + D′); m5, m7, m13, m15 → (B′ + D′).
POS: F = (A + D′)(B′ + D′) · SOP: F = D′ + AB′ (columns 00 and 10 → D′; row 10 → AB′).

Problem 10 — F = Σm(0, 1, 4, 5, 10, 11, 14, 15)

AB \ CD00011110
001100
011100
110011
100011
  • Two quads: A′C′ (top-left), AC (bottom-right).
SOP: F = A′C′ + AC (= A ⊙ C, XNOR) · POS: F = (A + C′)(A′ + C)

Problem 11 — with Don’t-Cares: F = Σm(0, 2, 6, 8, 10, 13, 15) + d(5, 7)

AB \ CD00011110
001001
010XX1
110110
101001
  • Four corners → B′D′; m13, m15 with X5, X7 → BD; m6 remains → A′BC (with X7) or A′CD′ (with m2).
SOP: F = B′D′ + BD + A′BC (A′CD′ is an equally valid third term).
POS: F = (B + D′)(A′ + B′ + D)(B′ + C + D) — here X5 and X7 are taken as 0s only where useful; a don't-care can be 1 for SOP and 0 for POS.

Practice Problems

  1. Minimal SOP of F = Σm(0, 1, 2, 5, 8, 9, 10).
    Show answer

    B′C′ + B′D′ + A′C′D.

  2. Minimal POS of F = ΠM(0, 2, 8, 10, 13, 15).
    Show answer

    (B + D)(A′ + B′ + D′).

  3. F = Σm(1, 3, 7, 11, 15) + d(0, 2, 5): minimal SOP and POS.
    Show answer

    SOP CD + A′B′ (or CD + A′D); POS D(A′ + C) — the POS is shorter.

  4. Simplify (A + B)(A′ + C)(B + C) algebraically.
    Show answer

    (A + B)(A′ + C) — B + C is the consensus term.

Common Pitfalls

  • Natural instead of Gray order — K-map columns run 00, 01, 11, 10, never 00, 01, 10, 11.
  • Missing wrap-around groups — the left and right edges, top and bottom edges, and the four corners are adjacent.
  • Writing POS literals like SOP — in a 0-group, a variable that is 0 appears uncomplemented and a 1 appears complemented.
  • Forcing every don't-care in — use an X only if it makes a group larger.
