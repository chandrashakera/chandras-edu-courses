Boolean Algebra: Axioms, Theorems & Properties

⏱ 22 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 2

Everything about how digital circuits behave — whether a design is correct, whether two different-looking circuits compute the same thing, how far an expression can be simplified — ultimately traces back to a small, formal set of rules. That's Boolean algebra: an algebraic system built specifically for variables that take only two values, and it's the mathematical foundation this entire course sits on.

Axiomatic Definition — Huntington's Postulates

A Boolean algebra is formally defined by a set of elements, two binary operators (+ for OR, · for AND), and one unary operator (′ for NOT), satisfying a specific list of postulates (due to E.V. Huntington, 1904). The essentials:

PostulateOR formAND form
Closurex + y is in the setx · y is in the set
Identity elementx + 0 = xx · 1 = x
Commutativex + y = y + xx · y = y · x
Distributivex + (y·z) = (x+y)·(x+z)x·(y+z) = x·y + x·z
Complementx + x′ = 1x · x′ = 0

Note the distributive law's OR form: x + (y·z) = (x+y)·(x+z) — this one has no equivalent in ordinary algebra (compare: in real-number arithmetic, a+(b×c) ≠ (a+b)×(a+c) in general). It's a genuine, defining feature of Boolean algebra specifically, not just a restatement of a familiar rule.

The Duality Principle

Every postulate above comes in a matched pair — swap every + with ·, every · with +, every 0 with 1, and every 1 with 0 in any true Boolean statement, and the result (its dual) is also guaranteed true. This isn't a coincidence to memorize separately; it falls directly out of how the postulates themselves are structured in symmetric pairs.

Basic Theorems

Theorems are derived from the postulates, not assumed independently — but in practice, they're used just as heavily as the postulates themselves for simplification work.

TheoremOR formAND form
Idempotentx + x = xx · x = x
Null (annulment)x + 1 = 1x · 0 = 0
Involution(x′)′ = x
Associativex + (y+z) = (x+y) + zx·(y·z) = (x·y)·z
Absorptionx + xy = xx(x+y) = x
DeMorgan's(x+y)′ = x′y′(xy)′ = x′+y′
🚀 DeMorgan's laws in plain language: "NOT (A OR B)" is the same as "(NOT A) AND (NOT B)," and "NOT (A AND B)" is the same as "(NOT A) OR (NOT B)." In circuit terms, this is precisely why a NOR gate can be redrawn as an AND gate with both inputs inverted, and a NAND gate as an OR gate with both inputs inverted — a fact you'll use constantly once gate-level implementation comes up.

Proving the Absorption Theorem from the Postulates

Theorems aren't handed down — they're provable from the postulates directly. Here's x + xy = x, proved step by step:

x + xy
= x·1 + x·y        (identity: x = x·1)
= x·(1 + y)        (distributive)
= x·1              (null theorem: 1 + y = 1)
= x                (identity)

Worked Example — Simplifying an Expression

Simplify F = AB + AB′ + A′B using the theorems above:

F = AB + AB′ + A′B
  = A(B + B′) + A′B        (distributive, factoring A out of first two terms)
  = A·1 + A′B               (complement: B + B′ = 1)
  = A + A′B                 (identity)
  = A + B                   (absorption-style identity: x + x′y = x + y)

Three terms and multiple gates collapsed down to a simple two-variable OR — this is exactly the kind of reduction that makes simplification worth doing before ever drawing a circuit.

Common Pitfalls

  • Applying ordinary-algebra intuition to the OR-distributive law. x + yz = (x+y)(x+z) is true in Boolean algebra but has no analogue in real-number arithmetic — don't dismiss it as "obviously wrong" just because it looks unfamiliar.
  • Confusing the complement theorem with the null theorem. x + x′ = 1 (complement) and x + 1 = 1 (null) look superficially similar but involve different terms — mixing them up during simplification produces wrong results.
  • Forgetting to flip both the operator AND the constants when taking a dual. The duality principle requires swapping +↔·, and 0↔1 together — swapping only the operators (or only the constants) doesn't produce a valid dual.

Applications

  • Every algebraic circuit simplification in this course — and every simplification a synthesis tool performs automatically inside a chip design flow — is built entirely from repeated application of these postulates and theorems.
  • DeMorgan's laws specifically are the algebraic justification for converting between AND/OR-based designs and NAND/NOR-based designs, which matters directly because NAND and NOR are often cheaper to fabricate than AND/OR gates.
  • Digital design verification tools use Boolean algebra's well-defined equivalence rules to prove two circuit implementations compute the exact same function, even when their gate-level structure looks completely different.
