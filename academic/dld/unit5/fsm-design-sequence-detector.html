FSM Design Procedure — Sequence Detector

⏱ 24 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 5

Unit 4's synchronous counter design procedure — state table → excitation table → K-map → circuit — generalizes directly to any FSM, not just counters. This topic runs the complete procedure on a real problem: a serial circuit that flags every occurrence of the bit pattern 1101 in an incoming input stream, including overlapping occurrences (e.g., in 1101101, both the first four bits and the last four bits are valid "1101" matches, sharing one bit).

Step 1 — State Diagram

Use a Mealy machine: each state tracks how much of "1101" has been matched so far by the tail of the input. On a mismatch, don't necessarily fall all the way back to "nothing matched" — check whether the tail still matches a shorter prefix of the pattern, which is exactly what makes overlapping matches work correctly.

S0 = matched "" (nothing relevant yet), S1 = matched "1", S2 = matched "11", S3 = matched "110". S3 is where the pattern completes: on input 1, S3 outputs 1 (match!) and jumps back to S1, not S0 — because the very bit that just completed "1101" is itself a "1," which is exactly the start of a possible new overlapping match. The other mismatch path from S3 — on a 0 — falls all the way back to S0, since no proper prefix of "1101" survives; S1 on a 0 does the same.

Step 2 — State Assignment

Four states need ⌈log₂4⌉ = 2 flip-flops. Using straightforward sequential assignment (Topic 3): S0=00, S1=01, S2=10, S3=11 — call the two state bits A (MSB) and B (LSB), and use JK flip-flops.

Reading JA: the single required 1 (at A=0,B=1,x=1) pairs with the don't-care directly below it (A=1, same B,x) — both cells have B=1,x=1 — giving the term Bx. KA's two required 1s sit in the A=1 row at Bx=11 and Bx=10 — both have A=1,B=1 — giving AB. JB and KB both need two separate pairings (worked the same way — match required 1s with adjacent don't-cares or with each other) to reach the two-term expressions shown.

The output y needs no map at all — it's a single required 1, at exactly A=1,B=1,x=1, with no don't-cares anywhere to exploit: y = ABx.

Step 5 — Circuit

Two JK flip-flops (A, B) hold the state; a small block of combinational logic — built straight from the five equations above — drives their J/K inputs and the output:

This is exactly the general Mealy structure from Topic 1, filled in with this design's specifics: the "J, K Logic" block is the four equations JA=Bx, KA=AB, JB=A′x+Ax′, KB=A′B+Ax′; the state register is the two JK flip-flops holding A and B; and "Output Logic" is the single gate y=ABx, reading the state and x directly — which is exactly why this is a Mealy machine and not a Moore one.

Common Pitfalls

  • Falling all the way back to S0 on every mismatch. That's the single most common bug in sequence-detector design — it silently breaks overlapping-match detection. Always check whether the mismatched tail still satisfies a shorter prefix of the pattern (S3 on a 0 does fall to S0, but S3 on a 1 — the completing case — goes to S1, not S0, because the input stream doesn't "forget" that trailing 1).
  • Forgetting the output is Mealy, not Moore. The match output is tied to the specific completing transition (S3 --1/1--> S1), not to any state itself — there's no "match state" that sits there outputting 1.
  • Skipping the excitation table and guessing the gate equations directly from the state diagram. With don't-cares in play, guessed equations routinely miss a legitimate simplification (or worse, get one wrong) — always go through the mechanical excitation-table-then-K-map steps.

Applications

  • Framing/synchronization logic in serial protocols (UART start bits, HDLC flag sequences) is built from exactly this kind of overlap-aware pattern detector, watching a continuous bitstream for a specific marker.
  • Simple intrusion/anomaly detectors and hardware string-matching (e.g., a fixed byte signature in a packet filter) use the same KMP-style "don't discard partial matches" state structure at a larger scale.
  • This exact procedure — state diagram to state table to excitation table to K-maps to gates — is the one general-purpose method this entire unit has been building toward; it applies unchanged to any FSM, not just pattern detectors.
