State Reduction & State Assignment

⏱ 18 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 5

Why Reduce States First?

A state table built directly from a word problem or spec often has more states than the behavior strictly requires — sometimes two states are, from the outside, completely indistinguishable. Since every state ultimately costs flip-flops (and every extra flip-flop costs excitation logic), merging redundant states before designing the circuit directly shrinks the final hardware, with zero change in observable behavior.

Equivalent States

Two states are equivalent if, starting from either one, every possible input sequence produces exactly the same output sequence. That reduces to a testable rule: states P and Q are equivalent if

1. Their outputs match for every input (immediately, for Mealy; or their own state output matches, for Moore), and 2. For every input value, the next states they go to are themselves equivalent (possibly recursively).

In practice: group states by matching output first, then within each group compare next-state columns — if two states' next-state entries land in the same group (even if the state names differ), merge them. Repeat until no more merges are possible.

Worked Example — Reducing 5 States to 3

Group by output first: {A, D, E} output 0, and {B, C} output 1. Within {B, C}: both rows read exactly (D, E) — identical — so B ≡ C. Within {A, D, E}: A's row is (B, C), but D's and E's rows both read (D, D) — identical to each other, and different from A's — so D ≡ E, while A stays on its own. Merging B with C (call the result B′) and D with E (call the result D′) gives:

State Assignment

A flip-flop stores a bit, not a letter — before the excitation equations (next topic) can be derived, every remaining state needs a unique binary code. For k states, the minimum number of flip-flops is ⌈log₂ k⌉ — 3 states need 2 flip-flops (2 bits can represent up to 4 states, with one code left unused).

Which specific code goes to which state is a free choice that never changes the FSM's external behavior — any valid assignment (no two states sharing a code) produces a functionally correct machine. What it does change is how simple or complex the resulting excitation equations turn out to be; finding the truly optimal assignment is a hard combinatorial search in general, so real designs either use a straightforward sequential assignment (simplest to reason about, used throughout this course) or lean on CAD tool heuristics for larger machines.

Worked Example — Assigning the Reduced Table

StateCode (Q₁Q₀)
A00
B′01
D′10

Substituting these codes for the state names turns the reduced table into one written entirely in binary — exactly the form the next topic's excitation tables and K-maps need to start from:

Q₁Q₀ = 00 (A): Next (x=0) = 01, Next (x=1) = 01, Output = 0 Q₁Q₀ = 01 (B′): Next (x=0) = 10, Next (x=1) = 10, Output = 1 Q₁Q₀ = 10 (D′): Next (x=0) = 10, Next (x=1) = 10, Output = 0 (code 11 is unused — a "don't-care" input combination for the excitation K-maps)

Common Pitfalls

  • Merging two states just because their outputs match. Matching output is necessary but not sufficient — their next-state behavior must also lead to equivalent states for every input, or merging them changes what the machine does.
  • Stopping after one round of comparison. Equivalence can be recursive — two states might only turn out equivalent once an earlier round has already merged the states their transitions point to. Keep repeating the comparison until a full pass produces no new merges.
  • Assuming a "better" state assignment is required for correctness. Every valid assignment (unique code per state) is functionally correct — the choice only affects circuit complexity, never whether the design works.

Applications

  • Logic synthesis tools (in an ASIC/FPGA toolchain) run automated state-minimization and state-assignment algorithms on every FSM in a design as a standard optimization pass, using exactly this equivalence definition under the hood.
  • Gray-code state assignment — where adjacent states in the sequence differ by only one bit — is a common special-purpose assignment strategy used specifically to reduce switching glitches in counters and simple sequencers.
  • One-hot encoding (one flip-flop per state, instead of the minimum ⌈log₂ k⌉) is a deliberately non-minimal assignment strategy still widely used in FPGAs, trading extra flip-flops (cheap and plentiful there) for simpler, faster excitation logic.
