4-Variable K-Maps

⏱ 20 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 3

Everything from the previous page — Gray-code headers, power-of-2 groups, wraparound adjacency — carries over directly to 4 variables. The only real difference is scale: a 4-variable map has 16 cells instead of 8, arranged as a 4×4 grid, and the wraparound now happens in two directions at once.

The Grid Layout

Both the rows (AB) and the columns (CD) use Gray-code order: 00, 01, 11, 10. That means rows wrap top-to-bottom (row 00 is adjacent to row 10), and columns wrap left-to-right (column 00 is adjacent to column 10) — the map behaves like the surface of a torus, not a flat rectangle.

Worked Example — F(A,B,C,D) = Σm(0,2,5,7,8,10,13,15)

AB\CD00011110
00 1m0 0m1 0m3 1m2
01 0m4 1m5 1m7 0m6
11 0m12 1m13 1m15 0m14
10 1m8 0m9 0m11 1m10

Two groups, each shown in a different shade above. The green cells — m0, m2, m8, m10 — are the map's four corners. In a 4-variable map, all four corners are mutually adjacent: row 00/row 10 wrap vertically, and column 00/column 10 wrap horizontally, at the same time. That makes the four corners a single valid quad:

Corners {m0, m2, m8, m10} (B=0, D=0 in all four; A and C both vary): term = B′D′
Blue quad {m5, m7, m13, m15} (B=1, D=1 in all four; A and C both vary): term = BD

F = B′D′ + BD

Every 1 in the map is covered by exactly one of these two quads, so F = B′D′ + BD is fully minimal.

🚀 Beyond the textbook: B′D′ + BD is exactly the definition of B XNOR D — this function is 1 precisely when B and D agree (both 0 or both 1), regardless of A and C. K-map groupings frequently reveal a recognizable named function hiding inside a longer minterm list, the same way Unit 2 of the Combinational Logic unit's XOR example did.

Grouping Sizes at 4 Variables

Group sizeVariables eliminatedTerm length
1 cell04 literals (the full minterm)
2 cells (pair)13 literals
4 cells (quad)22 literals
8 cells (octet)31 literal
16 cells (whole map)4F = 1 (constant)

The pattern from the 3-variable page continues exactly: each doubling of group size eliminates exactly one more variable from the resulting term.

Common Pitfalls

  • Missing the corner-wraparound group. The four corners being mutually adjacent is the single most commonly overlooked adjacency in a 4-variable map — always check them explicitly before finalizing a grouping.
  • Only checking one direction of wraparound. Both the row wraparound (top edge ↔ bottom edge) and the column wraparound (left edge ↔ right edge) apply simultaneously — checking only one direction misses valid groups.
  • Trying to draw non-rectangular or non-square groups. Every valid K-map group forms a rectangle (accounting for wraparound) — an L-shape or diagonal set of cells is never a single valid group, no matter how many of them are 1.

Applications

  • 4-variable functions are extremely common in real combinational design — a 4-bit adder's carry logic, a hex-digit decoder, and small ALU control logic all routinely need 4-variable minimization.
  • Beyond 4 variables, K-maps become impractical by hand (a 5-variable map needs two overlaid 4-variable maps, or a 3D visualization) — this is exactly where automated tabular methods (Quine-McCluskey) and software logic synthesis take over.
  • The corner-wraparound pattern specifically reappears in memory address decoding, where the highest and lowest addresses in a block can end up logically adjacent in exactly this way.
