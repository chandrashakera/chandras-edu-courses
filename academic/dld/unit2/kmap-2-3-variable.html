K-Maps: 2 & 3 Variables

⏱ 20 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 3

Unit 1 showed how to write any Boolean function as a canonical sum of minterms, straight from a truth table — mechanical, but rarely minimal. Algebraic simplification (also from Unit 1) can shrink it, but requires spotting the right theorem to apply at each step, and it's easy to stop too early or make a mistake. The Karnaugh map (K-map) replaces that trial-and-error with a visual procedure: arrange the truth table into a grid where the answer becomes something you can basically just see.

The Key Idea: Adjacency

A K-map arranges every row of a truth table into a grid, laid out so that physically adjacent cells differ in exactly one variable. That's not a coincidence — the row and column headers are deliberately written in Gray code order (00, 01, 11, 10 — never plain binary counting order 00, 01, 10, 11), specifically so neighboring cells are always exactly one bit-flip apart. Two cells that differ in exactly one variable can always be combined algebraically, since that differing variable cancels out (x + x′ = 1) — a K-map just lets you see which cells qualify, instead of hunting for the right algebraic step by hand.

2-Variable K-Map

A 2-variable map has 4 cells — one per row of a 2-variable truth table.

Worked Example — F(A,B) = Σm(0,1,3)

A\B01
0 1m0 1m1
1 0m2 1m3
Top row → A′ Right column → B

Two groups of adjacent 1s are visible: the top row (m0, m1 — both A=0) and the right column (m1, m3 — both B=1). Each group's size-2 means one variable drops out, leaving only the variable(s) that stay constant across the whole group:

Top row (A=0, B varies):     term = A′
Right column (B=1, A varies): term = B

F = A′ + B

Notice cell m1 belongs to both groups — that's completely normal. A K-map group only needs to cover a 1; nothing stops a 1 from being covered by more than one group if that produces fewer, larger groups overall.

3-Variable K-Map

A 3-variable map has 8 cells: 2 rows (for the first variable) by 4 columns, with the column header in Gray-code order — 00, 01, 11, 10, not 00, 01, 10, 11. This means the leftmost and rightmost columns are also adjacent (both differ from each other in exactly one bit), wrapping the grid around like a cylinder.

Worked Example — F(A,B,C) = Σm(0,1,2,3,5)

A\BC00011110
0 1m0 1m1 1m3 1m2
1 0m4 1m5 0m7 0m6
Top row → A′ Pair {m1,m5} → B′C

Two groups cover every 1: the entire top row (a group of 4, since the whole A=0 row is 1s) and a pair {m1, m5} (both B=0, C=1, differing only in A). Reading each group's constant variables:

Top row, all 4 cells (A=0, B and C both vary): term = A′
Pair {m1, m5} (B=0, C=1, A varies):            term = B′C

F = A′ + B′C

Check against the canonical form: minterms 0,1,2,3 are exactly the A=0 row (A′), and minterm 5 is covered by B′C — together, {0,1,2,3,5} matches the target exactly. ✓

🚀 A group's size is always a power of 2 — 1, 2, 4, 8... A group of size 2ⁿ eliminates exactly n variables from the term. A single isolated 1 (group of 1) keeps every variable; a group covering the whole map (size 2ᵏ for a k-variable map) means the function is simply 1, with every variable eliminated.

Grouping Rules, Stated Precisely

  • Every group's size must be a power of 2 — 1, 2, 4, 8. Groups of 3, 5, 6, or 7 cells are not valid.
  • Every 1 in the map must be covered by at least one group — an uncovered 1 means the resulting expression is wrong (missing a term).
  • Make groups as large as possible. A bigger valid group always produces a shorter term (fewer literals) than covering the same cells with several smaller groups.
  • Use the fewest groups that cover every 1. Overlap between groups is fine and often necessary — just don't add a group that's not covering any 1 that isn't already covered elsewhere.

Common Pitfalls

  • Writing column/row headers in plain binary order instead of Gray code. This breaks the entire premise of the K-map — adjacent cells would no longer differ in exactly one bit, and the visual grouping technique stops being valid.
  • Forgetting wraparound adjacency. In a 3-variable map, column 00 and column 10 (the leftmost and rightmost) are adjacent — a common mistake is treating the map as a flat, non-wrapping grid.
  • Making a group that isn't a power-of-2 size — e.g., grouping 3 cells together. If a grouping doesn't cleanly divide into 1, 2, 4, or 8, it isn't a valid K-map group, even if all those cells happen to be 1.

Applications

  • Every combinational circuit design in the rest of this course, and in real digital design workflows, starts with exactly this kind of minimization before a gate-level circuit gets drawn.
  • Manual minimization for small functions (up to 4-5 variables) is still routinely done with K-maps in coursework and quick hardware prototyping, even though larger designs use automated logic synthesis tools.
  • The same adjacency principle — Gray code ensuring single-bit transitions — is reused directly in Unit 4's counter and encoder designs, where Gray code sequencing prevents multiple bits from changing simultaneously.
