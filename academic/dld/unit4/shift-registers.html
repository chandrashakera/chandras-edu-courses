Shift Registers & Applications

⏱ 18 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 6

What is a Shift Register?

A shift register is a cascade of flip-flops sharing one common clock, where each stage's D input is simply the previous stage's Q — so on every clock pulse, every stored bit moves one position down the chain:

Whether a register counts as "serial" or "parallel" on each side is purely about how data gets in and out — the internal shifting structure above never changes.

Four Data Transfer Modes

SIPO taps every stage's Q as a separate output pin instead of using only the last one; PISO adds a way to force each stage directly to an external bit value before shifting begins. Both are the exact same shift-register core above with extra access points, not a different circuit.

Ring Counter

Feed the last stage's output straight back into the first stage's input, with no external serial data at all, and the register becomes a self-contained counter — a ring counter:

  • Number of states: N states for N flip-flops — the single 1 (or single 0) just circulates.
  • 4-bit sequence, pre-loaded to 1000: 1000 → 0100 → 0010 → 0001 → 1000 …
  • Must be pre-loaded (e.g., to 1000) — reset alone gives 0000, which is a valid-looking but stuck state: Q₃=0 feeds D₀=0 forever, so it never starts circulating on its own.

Johnson Counter (Twisted-Ring Counter)

Feed back the inverted last output instead of the plain one, and the single circulating bit becomes a spreading/retreating band of 1s and 0s:

  • Number of states: 2N states for N flip-flops — twice the ring counter, since the inverted feedback takes twice as long to return to the starting pattern.
  • 4-bit sequence, starting from reset (0000): 0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000 …
  • Self-starting from the all-0 reset state — unlike the ring counter, 0000 isn't a stuck state here, because Q₃′=1 feeds D₀=1 on the very next clock, immediately kicking off the sequence.

Common Pitfalls

  • Powering up a ring counter and expecting it to count. Without pre-loading exactly one stage to 1, a ring counter can power up in the all-0 (or, depending on design, all-1) state and simply sit there forever — it needs an explicit preset pulse before the first clock.
  • Forgetting Johnson counters need external decoding to identify each state. Unlike a ring counter, where the single active bit directly tells you the state, a Johnson counter's states aren't one-hot — identifying "which of the 2N states is this" needs a small 2-input gate per state (comparing adjacent bits).
  • Confusing SIPO/PISO direction. SIPO means data goes in one bit at a time and comes out all at once; PISO is the reverse. The "S" always refers to how data enters, the second "S"/"P" to how it exits.

Applications

  • UART serial communication is the textbook SIPO/PISO pairing — a transmitter's parallel byte is shifted out one bit at a time (PISO), and the receiver reassembles incoming bits back into a parallel byte (SIPO).
  • Johnson counters are used to build glitch-free ring oscillators and simple state sequencers (e.g., traffic-light controllers) since each state differs from its neighbor in only one bit, avoiding decoding glitches from multiple bits changing at once.
  • LED chaser / marquee displays are a direct, visible application of a ring counter — the single circulating 1 lights exactly one LED at a time, moving down the strip each clock pulse.
