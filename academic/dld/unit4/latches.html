Latches

⏱ 16 min read 📝 Quiz inside 📖 Mano & Ciletti Ch. 5

Combinational vs. Sequential Logic

Everything in Units 1–3 was combinational: output depends only on the present inputs, with no memory of anything that happened before. A sequential circuit adds memory — its output depends on both the present inputs and the circuit's current state, and that state comes from feeding an output signal back into the input logic:

Next State (Qnext) = f(Inputs, Current State Q)

A latch is the simplest possible sequential element — a 1-bit memory cell built from nothing but ordinary gates wired with feedback.

The SR Latch (Set-Reset)

Cross-coupling two NOR gates — each gate's output feeding back as one of the other gate's inputs — produces a circuit with two stable states, which is exactly what's needed to remember one bit:

Top gate: Q = NOR(R, Q′). Bottom gate: Q′ = NOR(S, Q). Each gate's own output loops around and back into the other gate — that crossing of the two feedback paths is exactly what "cross-coupled" means, and it's the reason S ends up wired to the gate that produces Q′, not Q.

Functionality

S (Set)R (Reset)QnextStateBehavior
00QHoldNo change — holds current state.
101SetForces Q to 1.
010ResetForces Q to 0.
11InvalidForbiddenBoth Q and Q′ driven to 0, breaking Q = Q̄′. Must be avoided.

Trace S=1, R=0 through the circuit above: the bottom gate sees S=1 on one input, so Q′=NOR(1, anything)=0 regardless of the other input; feed that Q′=0 back into the top gate along with R=0, and Q=NOR(0,0)=1. So S=1 does correctly force Q=1 — it just does it by first forcing the other gate's output low, then letting that feed forward.

The Gated D Latch

The SR latch has two problems for practical use: the forbidden S=R=1 state, and no control over exactly when it updates — right now it responds to S/R the instant they change. The Gated D Latch fixes both:

  • Drive the SR latch's inputs from a single data line D via S = D and R = D′ (D inverted). Since S and R are now always complements of each other, S=R=1 can never happen — the forbidden state is eliminated by construction.
  • Add an Enable (EN) input that gates D through to S and R only when EN=1, using two AND gates (one combining D·EN into S, the other D′·EN into R). When EN=0, both S and R are forced to 0 regardless of D, and the SR latch above just holds its last state.

Inside that box is exactly the SR latch drawn above, fed by D and D′ through the two enable-gated AND gates. Because S = D·EN and R = D′·EN can never both be 1 (D and D′ are always opposite), and because the latch only changes when EN=1, this circuit behaves as pure 1-bit data storage: while EN is high the output tracks D, and dropping EN freezes whatever was there.

Transparent vs. Latched Mode:
  • EN = 1 (Transparent): Q follows D continuously — any change on D immediately shows up on Q.
  • EN = 0 (Latched): Q holds its last value, completely ignoring further changes on D.

Common Pitfalls

  • Driving a plain SR latch with S=R=1. This isn't just "an invalid input" the way an unused decoder line is — it actively breaks the Q=Q̄′ complementary relationship the latch depends on, and the resulting state when S and R both return to 0 is a race, not a defined value.
  • Assuming a latch only updates on a clock edge. A latch is level-sensitive — a gated D latch tracks D for the entire time EN is high, not just at one instant. Edge-sensitive behavior is what flip-flops (next topic) add on top of this.
  • Forgetting the latch is the memory element inside the flip-flop. Every flip-flop discussed next is built from latches like this one — understanding the latch's transparent/latched behavior is a direct prerequisite for understanding why flip-flops need two latches (master-slave) to become edge-triggered.

Applications

  • Address latches in microprocessor systems (e.g., the 8085's ALE-controlled latch) hold a multiplexed address bus value stable using exactly this transparent/latched behavior.
  • Debounce circuits for mechanical switches sometimes use an SR latch directly — a single flick of a switch between two contacts cleanly sets or resets the latch once, instead of producing a burst of noisy transitions.
  • Every flip-flop — the subject of the next topic — is internally built from two of these latches in a master-slave arrangement.
